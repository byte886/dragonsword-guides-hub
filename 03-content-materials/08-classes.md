# DragonSword Awakening Classes 素材

## 重要说明

DragonSword: Awakening **没有传统的可切换职业系统**（如战士/法师/牧师的职业选择或转职系统）。游戏采用19个固定可玩角色的设计，每个角色有独特的 Hero Trait、状态异常能力和战斗定位。

玩家搜索 "classes" 时通常想了解：
1. 角色的战斗定位/类型（DPS、Support、Tank、Control等）
2. 角色的攻击类型（近战/远程）
3. 角色的状态异常属性
4. 各角色的头衔/职业称号（背景设定）

## 与传统职业系统的区别

| 传统职业系统 | DragonSword: Awakening |
|------------|----------------------|
| 选择一个职业，可转职 | 19个固定角色，不可转职 |
| 同职业角色玩法相似 | 每个角色有独特Hero Trait和技能 |
| 职业决定装备和技能 | 角色决定状态异常和战斗定位 |
| 通常有坦克/输出/治疗铁三角 | 更灵活，角色可兼具多种职能 |
| 职业平衡补丁影响大 | 角色平衡补丁影响单个角色 |

**建议：** 建站时如果用户搜索"classes"，应解释游戏没有传统职业系统，引导用户查看角色列表和战斗定位分类。
