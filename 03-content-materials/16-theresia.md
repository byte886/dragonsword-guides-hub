# DragonSword Awakening Theresia 素材

## Google素材

### 来源1：All Things How
- 素材来源地址：https://allthings.how/dragonsword-awakening-theresia-s-best-build-and-best-teams/
- 素材内容：

**角色定位：**
- 奥尔加纳教团的十位异端审判官之一
- 游戏中最自给自足的Bleed和Stun输出核心
- 自己就能施加两种状态异常，不需要setup队友
- 特质：Amplitude（振幅）
- 武器：双锤（pair of maces）
- 攻击范围比其他近战角色广，群怪和单体Boss都适用
- 速度不如Roxy或Reina，但每次攻击都能命中

**技能和Signal Skills：**

| 技能 | 类型 | 效果 |
|------|------|------|
| Consecration（奉献） | Active | 向前重击，留下旋转的锤子，激活时延长基础攻击链。施加Bleed |
| Celestial Verdict（神圣裁决） | Active | 跳跃并猛击地面，冲击时产生冲击波。施加Stun |
| Divine Arc（神圣弧光） | Signal Skill | 对Stunned敌人触发。接近目标并施加Bleed。主要爆发技能 |
| Holy Rise（神圣崛起） | Signal Skill | 对Bleeding敌人触发。重新施加Bleed并将目标打至Airborne |

**核心循环：** Consecration（Bleed）→ Celestial Verdict（Stun）→ 切换队友

**解锁方式：**
- Exchange Shop中的11个可兑换角色之一
- 每个角色需要1个Fate's Invitation
- 最快路线：完成她的Hero Quest获得Fate's Invitation
- 主线进度也会发放更多邀请券

**最佳配装（终局共识）：**

| 组件 | 推荐 |
|------|------|
| Karma | Merciful Death Sentence（专属Karma） |
| Gear | 3件Ruinsbreaker + 2件Holy Arbiter |
| 主属性 | ATK Power Up, Critical Hit Chance, Critical DMG |
| 副属性 | Additional Power, ATK Power Up, DEF Ignore |
| Rune | Resolve |
| 属性目标 | ~80%暴击率 / ~150%暴击伤害 |

**配装原理：**
- 3+2套装规则：3件一套大加成+2件另一套小加成
- Ruinsbreaker是近乎通用的3件核心，提供DEF Ignore穿透Boss护甲
- Holy Arbiter的2件效果匹配Theresia的角色定位（Stun伤害+15%）

**最佳队伍：Theresia + Roxy + Lute**
- 循环：
  1. Theresia起手，Consecration施加Bleed，Celestial Verdict落地Stun
  2. Stun触发Roxy的Signal Skill，切换到Roxy
  3. Roxy在目标被控制时快速连续攻击，延长Bleed
  4. Lute作为第三槽位，提供治疗和utility

## 操作技巧

1. **自己施加状态**：Theresia不需要队友setup，自己就能Bleed+Stun
2. **Consecration起手**：先施加Bleed，延长攻击链
3. **Celestial Verdict接Stun**：打开队友Signal Skill窗口
4. **Divine Arc是主要爆发**：对Stunned敌人触发，接近目标+施加Bleed
5. **Holy Rise可融入Airborne队**：对Bleeding敌人触发，打至浮空
6. **双锤范围广**：群怪时不容易miss
7. **觉醒后更强**：6级觉醒解锁被动和增强技能，暴击属性线才值得投入

## 常见错误

1. ❌ 不给她匹配元素的Karma
2. ❌ 用5件相同套装而不是3+2
3. ❌ 忽视DEF Ignore属性（Boss战关键）
4. ❌ 把她当纯输出而不利用状态异常
5. ❌ 早期就投入Exclusive Karma（先确定主C）
