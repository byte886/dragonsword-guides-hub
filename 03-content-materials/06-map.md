### 来源3：games.gg - Statues of Organa攻略
- 素材来源地址：https://games.gg/dragonsword-awakening/guides/dragonsword-awakening-guide-how-to-restore-all-statues-of-organa/
- 素材内容：

**Statues of Organa（奥尔加纳雕像）系统：**
- 类似黑暗之魂的篝火系统
- 找到散落的碎片并归还，解锁6个治疗充能（随时间恢复）
- 每个开放世界区域至少有一个
- 成功修复奖励Silver Key，可打开雕像附近的锁定宝箱（含高级战利品）
- 进入高级区域前先修复附近的雕像，获得恢复锚点

**全部13个雕像一览：**

| 雕像位置 | 所需碎片 | Boss遭遇 |  notable挑战 |
|---------|---------|---------|-------------|
| Shaded Tree Hill | 4 | 无 | 碎片散布在悬崖和灌木丛中 |
| Autumnleaf Zone | 3 | 无 | 湖中的碎片需要推树作桥 |
| Worm's Valley | 2 | 无 | 高级区域中最简单的 |
| Ruined Temple | 4 | 附近60级 | Boss房间碎片需要快速移动 |
| Dragon's Stonepeak | 3 | 无 | 敌人营地需要潜行接近 |
| Skyfeather Ridge | 3 | 无 | 最后碎片附近有57级敌人 |
| The Barren Old Trading Post | 3 | 60级巨魔 | 收集时敌人会攻击 |
| A Forgotten Haven | 3 | 无 | 碎片藏在岩石后的水中 |
| Two Lakes Hill | 2 | 无 | 整体最简单的雕像 |
| Stronghold Ridge | 4 | 无 | 第四个碎片在敌人营火附近 |
| Hill of Journey | 3 | 无 | 最后碎片附近注意蜜蜂 |
| Seagull Village | 3 | 25级野兽 | 适合有等级的玩家的早期Boss |
| Echo Canyon | 3 | 触发Boss | 最后碎片在高大的敌人悬崖上 |

**部分雕像详细位置：**

**Shaded Tree Hill（4个碎片）：**
- 碎片1：雕像周围倒塌的墙后面
- 碎片2：雕像北侧水边，藏在灌木丛中
- 碎片3：雕像东侧，敌人营地附近
- 碎片4：雕像东南侧，靠近悬崖

**Autumnleaf Zone（3个碎片）：**
- 碎片1：雕像基座周围的石栏杆后面
- 碎片2：湖中东南侧岩石顶部。不能直接游过去（碎片会下沉），需要找到湖边的树，互动并按住向前推树作桥
- 碎片3：西侧石柱顶部，骑Familiar爬上去拿
