**战斗核心循环：**
1. 一个角色设置状态异常（status ailment）
2. 第二个角色用Signal Skill响应
3. 第三个角色保持压力

**状态异常和Signal Skills工作原理：**
- 精英和Boss有重型动力装甲（power armor），普通攻击无法打破
- 攻击填充异常计量条（ailment gauge），填满后敌人陷入异常状态（Bleed、Stun、Airborne、Knockdown、Knockback等）
- 异常状态是回报，因为它打开了Signal机会
- 当场上英雄施加异常时，场外英雄头像会闪烁提示
- 按下匹配的切换按钮，同伴以Signal Skill入场——入场攻击伤害远高于普通技能，并叠加下一个异常
- **重要：** 仅看到头像闪烁不代表Signal已就绪，必须等待真正的异常状态，然后在狭窄窗口内切换

**队伍三个职能：**
- **Field driver（场上驱动者）**：保持活跃，创造下一个可重复条件
- **Signal answer（信号响应者）**：条件亮起时入场
- **Bridge（桥梁）**：延长压力或恢复间距，然后把战斗交回

**最佳全能队伍：Theresia + Reina + Castella**
- Theresia在Consecration和Celestial Verdict间切换，施加Bleed或Stun，Divine Arc提供游戏中最高爆发伤害之一
- Reina用Rising Cutter或Wind Slayer举起地面敌人并保持悬浮
- Castella对眩晕或倒地目标进行重击终结
- 三者协同：Theresia叠状态，Reina保持敌人浮空无法反击，Castella引爆连击

**按内容类型选择队伍：**

| 队伍 | 最佳用途 | 核心循环 |
|------|---------|---------|
| Theresia + Castella + Lute | Boss战 | Theresia输出，Lute破甲+utility，Castella在眩晕窗口爆发 |
| Theresia + Roxy + Castella/Lute | 高血量目标的Bleed | Consecration施加Bleed，Celestial Verdict加Stun，Roxy切入，Castella/Lute引爆 |
| Reina + Roxy + Ornette | 开放世界探索 | Reina快速结束战斗，Roxy衔接连击，Ornette护盾保护 |
| Theresia + Roxy + Lute | 精英敌人 | Bleed施加+破甲+眩晕，保持精英被控制 |
| Ornette + Castella + Alex/Lute | 重甲Boss | Ornette或Alex剥离动力装甲，触发Knockdown，Castella利用倒地伤害 |

**浮空连击队伍：Reina + Theresia + Roxy**
- 浮空是最强机制之一，因为悬浮的敌人无法反击或触发防御格挡
- Reina是主要浮空者，Theresia处理空中连击伤害，Roxy延长链条
- 替代浮空队：Reina + Castella + Lute/Aria
- **注意：** 当Super Armor让敌人无法被浮空时，浮空队价值下降，需准备破甲选项

**Tag Combo系统：**
- 实时切换3个英雄
- 叠加Status Ailments触发Signal Skills
- 释放毁灭性的Switching Signals进行连锁战斗
- Signal Skills是强大的奖励攻击，当Status Ailments在tag combos中叠加时触发

**核心机制（来自heroes页面）：**
- 每个英雄通过攻击应用主要Status Ailment
- 不同英雄的异常叠加在同一敌人上时触发Signal Skills——强大的奖励攻击造成巨大伤害
- 正确时机切换英雄触发Switching Signals，创造连锁连击
- Frost Gauge机制（Freeze英雄）：逐渐充能后触发完全冻结
- 3英雄实时切换，当所有三个英雄保持不同异常的uptime时，可实现无限异常链

**Signal Skill系统详解：**
- 每个角色有两个active skills，提供不同性能和状态效果
- 核心特征是Signal Skill——当这些效果发生时触发的特殊QTE技能
- 当状态效果触发时，不仅场上角色的Signal Skill激活，等待切换的角色也激活
- 动作公式：通过切换角色连续连锁这些技能
- 有效连接active和signal技能是游戏的核心

**战斗三步法：**
1. **主动技能（Active Skills）**：创造目标状态
2. **信号技能（Signal Skills）**：响应状态
3. **切换信号（Switching Signals）**：延续连击链

**练习方法：**
- 在耐打的敌人上练习，一次施加一种状态异常，等待信号提示，然后切换一次
- 当这个两步响应变得可靠时，再加入第三位英雄
- Boss也使用相同顺序：识别安全起手，保留后续攻击，敌人攻击需要闪避时中断连击链
- 闪避优先于完成序列

## 战斗核心原则

1. **异常状态是战斗的核心**：普通攻击只是填充计量条，真正的伤害来自Signal Skills
2. **队伍协同 > 个人伤害**：三个强大的角色不等于强大的队伍
3. **切换时机很重要**：必须在异常状态激活的狭窄窗口内切换
4. **闪避优先**：不要为了完成连击而吃伤害
5. **针对敌人类型调整队伍**：Boss需要持续伤害和破甲，开放世界需要机动和控制
6. **准备破甲选项**：Super Armor会阻止浮空/击倒，需要破甲角色
