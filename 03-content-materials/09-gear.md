# DragonSword Awakening Gear 素材

## Google素材

### 来源1：Nerd's Chalk
- 素材来源地址：https://nerdschalk.com/gear-sets-karma-dragonsword-awakening/
- 素材内容：

**核心原则：3+2套装搭配**

| 装备选择 | 结果 |
|---------|------|
| 3件A套装 + 2件B套装 | 激活定义角色定位的3件效果 + 次要的2件效果 |
| 5件相同套装 | 保持3件效果，但浪费2个可激活另一个加成的槽位 |
| 随机高稀有度散件 | 可能提升原始属性，但禁用build正在使用的套装加成 |

**重要：** 套装加成是稀有度之前首先要检查的东西。有用的配装通常是3件一套（3件效果）+ 2件另一套（第二个加成）。高稀有度掉落可能是降级——如果替换一个槽位导致3+2配置失效，套装加成的损失可能大于物品颜色或等级的提升。

**装备进度循环：**

| 系统 | 用途 |
|------|------|
| Dungeons（地牢） | 随着故事进度解锁更强阶段，farm更高级装备 |
| Merc Guide / Special Challenges | 查看哪个地牢掉落你需要的套装部件 |
| Currency dungeons（货币地牢） | farm矿石、金币、经验书、Karma卡、更高级升级材料 |
| Raids（副本） | 当装备等级支持符文槽时，farm符文和相关资源 |
| Upgrades（升级） | 花费矿石和金币将装备提升到当前上限 |
| Reforging（重铸） | 对满级装备使用Shape Grinder重掷副属性，锁定副属性时金币成本更高 |

**装备等级：**
- 低级装备等级上限低，副属性少
- 高级装备升级空间大，可达到15级
- 随着故事推进解锁更多地牢，相同套装会有更强等级版本

**基础套装：**
- 普通地牢奖励围绕基础护甲套装：Battle Will、Ballad of Life、Intruder
- 更多小众套装来自制作

**主属性和副属性：**
- 好装备不只是高级装备
- 冰霜输出角色从流血副属性中获得的价值很低（除非队伍确实使用流血）
- 眩晕、击倒、浮空、破防-focused角色需要滋养该职能的属性
- 生存属性对实际承受压力或需要uptime的Signal设置角色最重要
- **胸部槽位特别重要**：可携带护甲上最强的主属性值
- 使用Forging Mold（锻造模具）制作时可选择预期主属性，而不是接受随机结果

- 素材来源地址：https://games.gg/dragonsword-awakening/guides/dragonsword-awakening-beginners-guide/
- 素材内容：

**装备搭配原则：**
- 避免构建5件相同套装
- 全套加成在3件时激活，所以混合两套通常比纯套装产生更强的被动效果

**重铸系统：**
- 重铸需要Stat Grinder（每个25 Adventurer's Emblem奖牌）+ 金币
- 结果随机，视为渐进优化工具，而不是早期要激进farm的东西
- 副属性优先级排序：
  1. Critical Damage（暴击伤害）
  2. Attack Power（攻击力）
  3. Defense Ignore（防御穿透）
  4. Airborne Damage（浮空伤害）

## 装备系统核心原则

1. **3+2搭配 > 5件纯套装**：两套混合通常比纯套装更强
2. **套装加成 > 稀有度**：先检查套装数量再按装备
3. **匹配角色元素**：总是制作匹配角色元素的装备
4. **主属性选择**：胸部槽位最重要，用Forging Mold定制主属性
5. **重铸是后期优化**：不要早期投入太多资源，结果随机
6. **副属性优先级**：暴击伤害 > 攻击力 > 防御穿透 > 浮空伤害
7. **装备可升级到15级**：高级装备升级空间大
8. **制作 > 掉落**：大多数装备在铁匠铺制作，材料来自地牢和分解

## 与Build关键词的区别

- **Gear（装备系统）**：侧重于装备系统本身的机制（套装效果、获取方式、制作、升级、重铸、材料）
- **Build（角色构建）**：侧重于每个角色具体的配装选择（Karma、装备套装、属性、符文、队伍搭配）
