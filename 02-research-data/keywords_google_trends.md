- recipes / cooking（配方/烹饪系统）

### 第三梯队（补充内容）

### 不建议做（低价值/高风险）

- reddit（社区相关，留不住用户）
- gacha（搜索量下降快，且不是攻略内容）
- release date（时效性强，过时后没人搜）

## 五、重要发现

1. **角色名**：发现了5个具体角色名——theresia、lute、charlotte、reina、kalien，说明玩家已经在搜索具体角色的攻略了
2. **游戏系统**：发现了karma（业力）、recipes（配方）、cooking（烹饪）等系统，说明游戏有这些深度玩法
3. **交互式地图**：interactive map 搜索量在上升，说明玩家有地图探索需求
4. **作弊相关词搜索量很大**：mod、trainer、cheat engine 都在上升榜，但不适合我们做（广告联盟可能禁止）
5. **同类游戏对比**：granblue relink、grim dawn、genshin impact 等出现在相关词里，说明玩家会把这些游戏放在一起比较
6. **法律相关**：injunction decision（禁令裁决）出现在上升榜，可能游戏有侵权诉讼新闻
