# AI上下文交接指南

> 文档定位：给新会话的AI看的"快速上手指南"。照着本文档的步骤，可以在最少的对话轮次内理解项目全貌并开始工作。
> 核心问题：新开一个AI会话，AI对项目一无所知，怎么让它快速接手？
>
> **AI环境兼容性**：本文档集设计为AI无关（AI-agnostic），不绑定特定平台。已验证/可兼容的环境包括：
> - 豆包（Doubao）— 本项目原始开发环境
> - Claude（Anthropic）
> - ChatGPT / GPT-4o（OpenAI）
> - Cursor / CODEX（代码编辑器内置AI）
> - 其他支持文件读取和Markdown的AI助手
>
> 使用方法：将项目目录挂载/上传到目标AI环境，然后按下方"交接标准流程"操作。不同环境的文件访问方式可能不同（豆包用共享文件夹，Cursor用工作区，Claude用项目上传），但文档内容和操作流程完全一致。

---

## 一、交接标准流程

新窗口的AI按以下顺序阅读和理解：

```
第1步：读README.md（1分钟）→ 了解目录结构
第2步：读本文档（3分钟）→ 了解项目全貌和当前状态
第3步：读01-项目背景与决策日志（5分钟）→ 理解为什么这么做
第4步：根据任务读对应操作手册（按需）→ 知道怎么做
第5步：读对应数据/素材（按需）→ 拿到具体数据
```

## 五、用户偏好与工作方式（必须遵守）

### 5.1 沟通偏好
- **引导式教学**：拒绝直接给结论，偏好结合具体场景的通俗解释和详细操作流程
- **严格流程**：多步骤任务严格遵循预设流程，禁止跳步，关键节点主动确认
- **数据支撑**：调研/选工具要求可量化数据、多方案横向对比、信息来源标注
- **结构化输出**：要求严格的结构化格式（Markdown、JSON等）

### 5.2 内容质量要求
- **素材真实**：所有事实性内容必须来自真实来源，严禁AI凭空编造
- **多来源核验**：重要信息必须2个以上独立来源交叉验证
- **记录来源**：每个信息点都要记录来源链接

### 5.3 操作分工
- **AI自动执行**：搜索、整理、写代码、文件操作等非敏感操作
- **用户手动完成**：登录验证、密码输入、人机验证、支付购买等敏感操作

### 5.4 安全红线（绝对禁止）
- 作弊相关内容（mod、trainer、cheat、crack、key等）
- 成人内容
- 盗版/破解相关
- 社区引流词（reddit、discord等）

## 九、交接检查清单

新窗口的AI在开始工作前，应该能回答以下问题：

- [ ] 项目是做什么的？目标是什么？
- [ ] 选定了什么游戏？为什么选这个？
- [ ] 当前做到哪一步了？下一步是什么？
- [ ] 操作手册在哪里？怎么用？
- [ ] 数据和素材在哪里？
- [ ] 用户有哪些偏好和红线？
- [ ] 当前任务是什么？需要用什么方法论？

如果以上问题有任何一个答不上来，先回去读对应文档，不要盲目开始操作。
