## 三、数据更新标准流程

### 3.1 更新步骤（5步）

```
确认更新范围 → 重新采集数据 → 对比新旧差异 → 更新数据文件 → 记录变更日志
```

#### 第一步：确认更新范围
- 哪些数据需要更新？
- 更新原因是什么？（定期/事件驱动）
- 影响哪些页面和文档？

#### 第二步：重新采集数据
- 使用 05-operation-guides/ 中的标准方法重新采集
- 记录采集时间和使用的工具参数
- 确保采集方法与上次一致（保证可比性）

#### 第三步：对比新旧差异
- 列出变化的数据项
- 分析变化原因（游戏更新/季节因素/数据修正）
- 评估变化对网站内容的影响

#### 第四步：更新数据文件
- 更新对应的数据文件（keywords-cleaning.md、keywords.json、素材文件等）
- **不要直接覆盖**：在文件中保留变更记录，或在本文档的"数据变更日志"中记录
- 标注最后更新时间

#### 第五步：记录变更日志
在本文档"数据变更日志"中添加记录：
- 数据类型
- 变更内容
- 变更原因
- 变更时间
- 影响范围

### 3.2 数据更新的注意事项
- **保留历史**：重要数据的历史版本要保留，用于趋势分析
- **标注来源**：每条数据都要有来源链接和采集时间
- **验证准确性**：更新后的数据要交叉核验
- **同步更新**：如果关键词变了，对应的页面、素材、sitemap都要同步更新

## 四、各数据类型的更新要点

### 4.1 关键词更新
**操作要点**：
1. 重新用SimilarWeb查KD和搜索量
2. 重新用Google Trends查趋势
3. 检查是否有新的相关关键词出现
4. 更新keywords.json中的priority（高/中/低）
5. 如果有关键词被移除，记录原因

**判断标准**：
- KD上升>10 → 考虑降低优先级
- 搜索量下降>50% → 考虑移除
- 新关键词KD<30且搜索量>100 → 考虑加入

### 4.2 素材更新
**操作要点**：
1. 检查现有素材的信息源是否还有效
2. 搜索最新攻略，看是否有新信息
3. 更新素材文件中的内容
4. 更新信息源列表
5. 如果网站已上线，同步更新04-website/中的对应HTML

### 4.3 竞品分析更新
**操作要点**：
1. 重新访问竞品站点，看是否有新内容
2. 用SimilarWeb查竞品流量变化
3. 更新竞品的优势/劣势分析
4. 看是否有新的竞品出现

## 五、数据变更日志

- **操作人**：谁做的更新

## 六、数据质量检查

### 6.1 定期检查清单
每季度对数据资产做一次检查：

| 检查项 | 标准 | 通过 |
|--------|------|------|
| 关键词时效性 | 搜索量/KD数据在3个月内 | ☐ |
| 素材来源有效性 | 信息源链接可访问 | ☐ |
| 内容准确性 | 关键数据与最新游戏版本一致 | ☐ |
| 无重复数据 | 关键词无重复，素材无冗余 | ☐ |
| 来源标注完整 | 每条重要数据都有来源 | ☐ |
| 更新时间标注 | 每个数据文件有最后更新时间 | ☐ |

### 6.2 数据老化预警
出现以下情况时，数据可能已老化：
- 游戏发布了大版本更新但数据未更新
- 信息源链接404
- 玩家反馈内容与实际不符
- SimilarWeb数据与上次差异超过30%
