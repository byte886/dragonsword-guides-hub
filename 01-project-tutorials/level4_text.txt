01. 具体步骤
有了素材才能动工。这一关把第 4 关的调研成果变成真实的页面。
但建站有一个重要原则：不要从零搭前端。
新手从空白项目开始写前端，耗时耗 token，而且 SEO 和页面结构容易不专业。
更推荐的做法：找一个同类型的竞对游戏攻略站 → 参考它的前端效果和页面结构 → 打磨成自己的模板。
动手前记住
先上线，再打磨
"一个花两天匆忙上线但抢占了先机的'垃圾'站，很可能比一个花两周精心打磨但姗姗来迟的完美网站，能带来多得多的流量。"
新词竞争窗口很短。你越早上线，越容易获得优势。
首版再烂，能访问就是胜利。上线之后你会知道真实用户需要什么，而不是靠猜。

2. 第二步：找到参考对象&模仿
2.1 找到参考对象
找不到对标怎么办？如果你选的词很新，搜出来还没人做攻略站，别慌，两种办法：
1. 借鉴同类游戏优秀站：虽然没人在做"你这个游戏"，有大量跑通了的攻略站（各种抽卡类、角色养成类游戏的 wiki 站）。找一个你觉得好看，参照它的页面结构和排版，套到你这个游戏的内容上。
•如果选择参考对象？
优先挑选：新站，DR=0（或者 DR 数值很低，接近 0），排名靠前的网站（DR=0 或者接近 0 说明没怎么发外链，单靠网页结构将排名顶上去的）
如图就是一个 DR 等于 0 的网站

问 chatgpt：最近一个月steam 、roblox 上新了什么游戏如图：

选点进去参考页面结构设计，遇到功能和美观度都不错的就收藏下网址
（优秀网站的共性特征：导航栏、hero 区、tab 按钮、大标题等都是具备的，UI 美观，首页的板块承接了高搜索量的需求）
同样搜索第 2 个游戏词·······
参考优秀对象的页面结构、UI 布局等等

复刻时要注意（哪些能抄，哪些要改）：
•能参照的：页面结构（首页放哪几块）、导航方式、内容组织、配色风格。
•必须改的：所有文字内容、游戏名、具体数据——这些必须是你自己调研的真实内容，绝不能直接复制别人的。
•一句话：抄结构，不抄内容。
2.2 模仿
找到对标站后，有两种复刻方式（选你顺手的）：
2.2.1 方式一：用 Codex 复刻（主线，最简单）
把对标站 URL + 下面的复刻提示词发给 Codex（参考新手复刻提示词，降维版）：
复刻这个游戏站：[对标站首页 URL]，至少实现三个页面——
首页：[URL]、列表 / 导航页：[URL，如 /classes]、文章详情页：[URL，如 /classes/xxx]。
UI 布局完全参照目标站复刻，不要自行设计。
技术栈用 Next.js + 多语言 + MDX 写内容。
可选增强：
给 Codex 装个免费的 superpowers 插件，同样的复刻提示词，Codex 会自动走系统化流程——拆解设计 → 拆成小任务 → 逐任务执行 + 每步自检，比单句提示词更稳、少返工。Codex（App / CLI）和 Claude Code 都能装。
装法（任选一种）：
•Codex：在 Codex 的插件市场搜 superpowers 安装（App 在 Plugins 里找；CLI 输入 /plugins → 搜 superpowers → Install Plugin）
•Claude Code: /plugin marketplace add obra/superpowers-marketplace → /plugin install superpowers@superpowers-marketplace → /reload-plugins
装好后，把上面的【复刻提示词】发给它，superpowers 会自动接手：先问你 1-2 个问题确认复刻范围 → 写实现计划 → 你确认后逐任务执行 + 自检。新手可以先用一句提示词跑通，跑顺了再装 superpowers 提升稳定性。
2.2.2 方式二：用 same.new 把对标站直接克隆成代码
same.new 是一个 AI 网站克隆工具，给它对标站的 URL，它能直接把页面结构、配色、布局"抄"成可用的前端代码（React / Tailwind），省掉 AI 参照着从零写的环节。
费用：开通 25 美元（支持支付宝），够用 2-3 个站，模型选择 GPT 5.5 模型即可。
怎么用：
1. 打开 same.new，把对标站首页 URL + 复刻要求（参考上面的【复刻提示词】）一起给它——别只给 URL，否则克隆出来的代码目录结构、多语言、SEO 都不对，后面改造很麻烦
2. same.new 产出一个克隆的前端项目
3. 把这个项目交给 Codex，前端不一致的地方再进行修修补补
两种复刻方式怎么选：
•想最简单、不装额外工具 → 方式一 Codex + 复刻提示词（装了 superpowers 会更稳）
•想最快拿到对标站结构 → 方式二 same.new 克隆，方便但多次使用可能需要付费
2.3 第三步：把第 3 关调研的信息填进去
复刻出网站骨架后，分两步填信息：
1）首页用【信息填充提示词】一次填好；
2）每个内页（classes / codes / tier list / 长尾问题页），用【内页信息填充提示词】逐个填，输入是这个内页对应的关键词 + 你为它收集的信息。
首页填充：
把第 3 关用 ChatGPT 调研出的首页信息，填进复刻好的网站：
1. 全站旧游戏名 → 替换成我的游戏名（首页、页脚、侧边栏、法律页都要换，无残留）
2. 首页各模块（Hero / 新手引导 / 游戏介绍 / 兑换码 / 底部号召）用调研的真实文案
3. 官方链接（官网 / Discord / YouTube）、SEO title / description / keywords、主题色（HSL）、多语言，按调研结果配置
4. 侧边栏兑换码用调研的真实码；没有就写"暂无"，绝不编造
所有内容只写第 4 关调研的真实信息，不确定的标"待确认"，不要编造数值和兑换码。
内页填充（一个关键词一个内页：输入是单关键词 + 为它收集的信息）：
针对内页关键词，把收集到的信息过滤无效信息，整合收集的多源数据，然后填进各个内页。
一个关键词填一个内页，输入如下：
- 游戏关键词：keywords.json
- 为这个关键词收集到的真实信息（第 4 关调研的素材，贴在这里）：关键词素材.md
要求：
1. 页面 title 含这个关键词，40-60字符；meta description 含关键词、140-160 字符
2. 开头直接回答玩家的搜索问题，不绕弯
3. 全文1200字左右；分 H2 小节，每段 3-4 句，适合扫读；
4. 只写上面收集到的真实信息，不确定的标"待确认"
5. 不要编造数值、角色名、兑换码；
2.4 第四步：提交到 GitHub
代码在本地跑通后，提交到 GitHub（下一关部署要用）：
2.4.1 去 GitHub 网页、新建仓库：github.com → New repository，起个仓库名，不要勾选自动生成 README。
默认最后 private，外人不可见。
点击 code 栏目，找到该仓库地址并复制备用
2.4.2 把下面的提示词发给 Codex（填好自己的用户名和仓库名）：
【GitHub 提交提示词】
我的信息：上述仓库名。
帮我把当前项目推到 GitHub，依次执行：
1. git init → git add . → git commit -m "first version"
2. git remote add origin https://github.com/<我的用户名>/<仓库名>。git
3. git push -u origin main
如果远程仓库还没建：先暂停，告诉我去 github.com → New repository 建一个空仓库（不要勾自动生成 README），建好再继续。
2.5 第五步：最终确认
本地浏览器打开：所有页面能访问、内容能看、链接能点；
GitHub 仓库刷新一下，能看到你刚推送的代码。
