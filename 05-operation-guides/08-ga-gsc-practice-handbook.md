# GA & GSC 实践手册：游戏攻略站专用

> 针对 ds-guides.wiki（纯静态多语言游戏攻略站）的数据分析实践指南。
> 不是 GA/GSC 功能大全，只讲当前项目真正需要看的报告、怎么看、看完做什么。
> 最后更新：2026-08-23

---

## 1. 两个工具的分工

```
用户在 Google 搜索 "dragonsword awakening tier list"
        │
        ▼
   GSC 记录：展示了多少次、排第几、点了没点、搜什么词
        │
        ▼
   用户点击进入网站
        │
        ▼
   GA 记录：来了多少人、看了哪些页、停留多久、从哪国来、有没有回访
```

**一句话记忆**：GSC 看"用户怎么找到你"，GA 看"用户来了之后做了什么"。

---

## 2. 复盘节奏

| 频率 | 工具 | 看什么 | 耗时 |
|------|------|--------|------|
| 每周（7天） | GSC | 搜索效果 + 索引状态 | 10 分钟 |
| 每两周（14天） | GA + GSC | 全部核心报告（见下方清单） | 30 分钟 |
| 每月（30天） | GA + GSC + SimilarWeb | 核心报告 + 竞品对比 | 60 分钟 |

## 3. GA 必看报告（每两周）

### 3.1 流量获取（Traffic Acquisition）

**路径**：报告 → 了解网站流量 → 流量获取

**看什么**：
- `Organic Search`（自然搜索）人数和占比 — SEO 是否生效的核心指标
- `Direct`（直接访问）— 书签、直接输入、未识别来源
- `Referral`（引荐）— 从其他网站点链接来的，反映反链建设效果
- `Social`（社交）— Reddit、Discord、Twitter 等社交平台来的

**本项目基准**（上线 8 天）：Organic 50%、Direct 50%、Referral 0%、Social 0%

**行动判断**：
- Organic 占比持续上升 → SEO 有效，继续
- Referral 为 0 超过 30 天 → 需要开始反链建设（Reddit、Discord、游戏论坛）
- Direct 占比异常高（>70%）→ 可能是 GA 追踪代码问题或流量来源未正确标记

### 3.2 网页和屏幕（Pages and Screens）

**路径**：报告 → 互动度 → 网页和屏幕

**看什么**：
- 浏览量前 10 的页面 — 哪些内容最受欢迎
- 每个页面的"平均参与时间" — 内容是否有价值
  - 攻略页 >1 分钟 = 好，<10 秒 = 用户没找到想要的
- "每位活跃用户的浏览量" — 是否只看一页就走
- 对比 GSC 中有展示但 GA 中没流量的页面 — 排名有但标题不吸引人

**本项目基准**：首页 101 次/11 秒（跳出严重），韩文 gear 页 20 次/1分34秒（深度参与）

**行动判断**：
- 首页停留 <15 秒 → 优化首屏，增加"热门攻略"入口
- 某页面流量高但时间短 → 内容可能不匹配搜索意图，检查标题和内容是否一致
- 新页面上线 7 天后仍无浏览 → 检查是否被收录、是否有内链指向

### 3.3 国家/地区（Country）

**路径**：报告 → 用户 → 受众特征详情 → 国家/地区

**看什么**：
- Top 10 国家的用户数
- 各国"参与度"差异 — 哪个国家的用户真正在看内容
- 对比网站 5 语言（en/ko/ja/ru/zh）的目标市场

**本项目基准**：美国 115 人/参与率 13%（疑似机器人），韩国 32 人/参与率 66%（最高质量）

**行动判断**：
- 美国流量大但参与率 <15% → 可能是机器人或误点，检查 GA 机器人过滤设置
- 韩国/俄罗斯参与率高 → 优先补充韩文/俄文内容
- 某语言对应国家无流量 → 检查该语言版本是否被正确收录

### 3.4 事件（Events）

**路径**：报告 → 互动度 → 事件

**看什么**：
- `page_view` — 总浏览量
- `user_engagement` — 参与用户数（停留 >10 秒或有互动）
  - 参与率 = 参与用户 / 总用户，健康值 >40%
- `scroll` — 滚动用户数，健康值 >40%
- `click` — 点击用户数，如果极低可能是导航问题

**本项目基准**：参与率 51%、滚动率 21%、点击 6 次（偏低）

**行动判断**：
- 参与率 <25% → 紧急，内容或首屏有问题
- 滚动率 <20% → 用户看不到下方内容，改进首屏引导
- 点击数异常低 → 检查导航是否可用、GA 增强衡量是否开启

### 3.5 留存（Retention）

**路径**：报告 → 留存

**看什么**：
- 新用户数 vs 回访用户数
- 回访率 = 回访用户 / 新用户
- 按同类群组的留存曲线（第 0/7/14/21/28 天）

**本项目基准**：新用户 305、回访 27（8.9%）

**行动判断**：
- 攻略站回访率目标 >15%（玩家会回来查更新）
- 回访率低 → 增加更新频率、添加"最近更新"模块、考虑邮件订阅
- 新站前 30 天回访率低是正常的，持续观察

### 3.6 技术详情（Tech Details）

**路径**：报告 → 技术 → 技术详情

**看什么**：
- 浏览器分布（切换维度为"浏览器"）— 确保主流浏览器兼容
- 设备类别（切换维度为"设备类别"）— 桌面/移动/平板比例
  - 如果 GA 中切换维度困难，可用 GSC 的设备数据替代

**本项目基准**：Chrome 69%、Edge 11%、Safari 10%；桌面 66%/移动 34%（来自 GSC）

**行动判断**：
- 移动占比 >50% → 优先优化移动端体验
- 某浏览器占比 >5% 且有报错 → 检查兼容性
- Safari 占比高 → 确保 iOS Safari 测试通过

### 3.7 实时报告（Realtime）

**路径**：报告 → 实时

**什么时候看**：
- 刚部署完 GA 或新页面，确认代码生效
- 发了推广链接，看实时流量
- 怀疑网站挂了

**看什么**：过去 30 分钟活跃用户数、当前页面、来源国家、设备

## 4. GA 暂不需要看的报告

| 报告 | 不看的原因 | 什么时候需要看 |
|------|-----------|---------------|
| 用户获取（User Acquisition） | 新站首次互动渠道与会话渠道几乎一致 | 投放广告或有 UTM 活动时 |
| 转化（Conversions） | 未配置关键事件 | 配置了"查看3+页面"等转化事件后 |
| 广告（Advertising） | 没有投广告 | 接 AdSense/Adsterra 后 |
| 探索（Explorations） | 自定义分析，基础复盘不需要 | 需要漏斗分析、路径分析、用户分群时 |
| 落地页（Landing Pages） | 新站页面少，网页报告已覆盖 | 页面数 >50 或做推广落地页时 |
| 电子商务/变现 | 纯内容站不适用 | 永远不看（除非卖东西） |
| 用户生命周期价值 | 需要长期数据 | 上线 90 天后 |
| 广告活动/UTM | 没有推广活动 | 开始做推广时 |
| 引荐/社交详情 | 当前流量为 0 | 有引荐/社交流量后 |

## 5. GSC 必看报告

### 5.1 搜索效果（Performance）— 每周

**路径**：效果 → 搜索效果

**四个核心指标**：

| 指标 | 含义 | 健康基准 |
|------|------|---------|
| 点击（Clicks） | 从 Google 搜索进入网站的次数 | 持续增长 |
| 展示（Impressions） | 在搜索结果中被看到的次数 | 持续增长 |
| CTR | 点击 ÷ 展示 | >5% |
| 平均排名 | 搜索结果中的平均位置 | <10（第一页） |

**必须切换四个维度查看**：

1. **查询（Queries）**：
   - 按点击排序 → 哪些词真正带来流量
   - 按展示排序 → 高展示低 CTR 的词（优化标题/描述）
   - 找有展示但无落地页的词 → 内容缺口（补页信号）

2. **网页（Pages）**：
   - 哪些页面在搜索中表现最好
   - 高展示低点击的页面 → 优化 title/description

3. **国家（Countries）**：
   - 与 GA 国家数据对比，判断流量质量

4. **设备（Devices）**：
   - 桌面 vs 移动比例
   - 如果移动排名明显差于桌面 → 检查移动端体验

**日期范围**：默认最近 3 个月。每周复盘时选最近 7 天，与上周对比。

### 5.2 网页索引（Pages）— 每周

**路径**：索引 → 网页

**看什么**：
- 已编入索引的数量 — 应接近网站总页面数
- 未编入索引的数量及原因：
  - `已发现 - 尚未编入索引` — Google 知道但还没爬，等待即可
  - `已抓取 - 尚未编入索引` — 爬了但没收，可能内容质量不够
  - `重复网页` — canonical 设置问题
  - `未找到（404）` — 页面不存在，检查链接
  - `被 noindex 排除` — 代码问题

**本项目基准**：89 已收录、43 未收录（30 个"已发现未收录"，新站正常）

**行动判断**：
- 已收录比例 >90% → 健康
- 已收录比例 <70% → 排查技术问题
- 新页面上线 14 天后仍未收录 → 在 GSC 中请求索引
- 404 错误 → 修复或设置 301 重定向

### 5.3 站点地图（Sitemaps）— 每月

**路径**：索引 → 站点地图

**看什么**：
- 状态是否为"成功"
- 最后读取时间
- 已发现的网址数是否接近实际页面数

**行动**：
- 添加新页面后重新提交 sitemap
- 如果状态异常，检查 sitemap URL 是否可访问

### 5.4 URL 检查（URL Inspection）— 按需

**路径**：顶部搜索框输入 URL

**什么时候用**：
- 发布重要新页面，点击"请求编入索引"加速收录
- 某页面排名突然消失，检查是否被移除索引
- 排查页面为什么没被收录

**看什么**：
- 网址是否在 Google 索引中
- 编入索引的规范页面
- 移动设备可用性
- 网页抓取信息（上次抓取时间、抓取方式）

## 6. GSC 暂不需要看的报告

| 报告 | 不看的原因 | 什么时候需要看 |
|------|-----------|---------------|
| 网页体验（Core Web Vitals） | 新站数据不足，纯静态站性能好 | 上线 30 天后月度检查 |
| 移动设备易用性 | 响应式 CSS 已适配，GA 无报错 | 移动端流量异常时 |
| 链接报告 | 新站外链极少，内链通过内容关联图管理 | 开始反链建设后 |
| 安全问题和手动操作 | 正常站应为空 | 每周扫一眼是否有通知 |
| 移除工具 | 不需要移除页面 | 需要下架页面时 |
| 国际化定位 | hreflang 通过代码验证脚本检查 | 多语言出现排名问题时 |
| 抓取统计 | 新站数据少 | 月度检查 |
| 设置 | 验证已完成 | 更换域名或验证方式时 |
| 关联设置 | GA/GSC 同账号已关联 | 新增 GA 资源时 |

## 7. SimilarWeb（每月）

**什么时候看**：上线 30 天后，且月访问量达到 5000+

**看什么**：
1. 自己的站点：总流量趋势、流量来源、关键词排名（如果有数据）
2. 竞品站点（games.gg、destructoid.com、thegameswiki.com）：
   - 月度访问量和趋势
   - 流量来源分布（自然搜索占比、引荐来源）
   - 热门关键词（找关键词差距）
   - 引荐网站（找反链机会）
   - 受众兴趣（找内容方向）

**注意**：SimilarWeb 数据是估算值，用于趋势对比和竞品参照，不作为精确数据。

## 8. 复盘操作流程

### 每周 GSC 快查（10 分钟）

1. 打开 GSC → 搜索效果 → 日期选最近 7 天
2. 记录：点击、展示、CTR、排名，与上周对比
3. 切换到"查询" → 找高展示低 CTR 的词
4. 切换到"网页" → 找高展示低点击的页面
5. 打开"网页"索引 → 检查收录数是否增长
6. 扫一眼安全问题/手动操作（应为空）

### 每两周完整复盘（30 分钟）

1. GSC 搜索效果（4 个维度都看）
2. GSC 索引状态
3. GA 流量获取
4. GA 网页和屏幕
5. GA 国家/地区
6. GA 事件（参与率、滚动率）
7. GA 留存
8. 填写复盘报告（用 `.agents/skills/data-review/SKILL.md` 中的模板）
9. 更新决策日志
10. 列出行动项

### 每月竞品分析（60 分钟）

1. 完成每两周复盘的所有内容
2. SimilarWeb 查看 2-3 个竞品
3. 对比流量来源、关键词、引荐站
4. 更新关键词缺口列表
5. 调整下月内容计划

## 11. 常见问题

**GA 实时报告显示 0 个用户**
1. 确认 `js/analytics.js` 中 Measurement ID 正确
2. 用无痕模式访问网站，排除插件拦截
3. 检查广告拦截插件是否阻止 GA
4. 查看页面源码确认 analytics.js 被引用

**GSC 和 GA 数据对不上**
- 正常。GA 记录实际访问，GSC 记录搜索展示/点击
- GA 可能被广告拦截器阻止，GSC 数据来自 Google 搜索日志
- 时间延迟不同：GA 24-48 小时，GSC 2-3 天

**GSC 显示"已发现 - 尚未编入索引"**
- 新站常见，Google 还没安排抓取
- 等待 1-2 周，或用 URL 检查工具请求索引
- 如果数量持续增加但不收录，检查内容质量和站点权重

**美国流量大但参与率极低**
- 可能是机器人流量（新站常见）
- 检查 GA 管理 → 数据设置 → 数据过滤器 → 开启机器人过滤
- 观察 2-4 周，通常会自然下降

**新页面多久能在 GSC 看到数据**
- 提交 sitemap 或请求索引后：3-7 天开始抓取
- 收录后：2-3 天开始有展示数据
- 有点击数据：取决于排名和搜索量，可能 1-4 周
