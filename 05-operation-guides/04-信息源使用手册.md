# 信息源使用手册

> 文档定位：**操作手册**。教你如何检索、核验、更新信息源，而不是简单的来源清单。
> 核心原则：所有事实性内容必须来自真实来源，严禁AI编造；重要信息必须交叉核验。

---

## 一、信息源分类与特点

### 1.1 五大类来源

| 类别 | 可信度 | 优势 | 劣势 | 适用场景 |
|------|--------|------|------|---------|
| 官方渠道 | ⭐⭐⭐⭐⭐ | 最权威、一手信息 | 更新可能不及时、内容偏宣传 | 基础信息、更新公告、数据确认 |
| 英文头部攻略站 | ⭐⭐⭐⭐ | 内容专业、结构清晰 | 可能有错误、深度有限 | 核心攻略、配装、队伍 |
| Wiki站点 | ⭐⭐⭐⭐ | 信息全面、结构化 | 更新慢、可能过时 | 角色基础信息、世界观、术语 |
| 小语种攻略站 | ⭐⭐⭐ | 常有独家深度内容 | 语言障碍、质量参差不齐 | 配队细节、技能数值、角色背景 |
| 社区/视频 | ⭐⭐ | 最新发现、玩家实测 | 质量参差不齐、可能有误 | 操作技巧、最新机制、争议讨论 |

### 1.2 可信度使用原则
- **官方渠道**：可直接采用，标注"官方"
- **英文头部攻略站**：可采用，重要数据需第二个来源验证
- **Wiki**：基础信息可采用，数值类需验证
- **小语种站**：独家内容可采用，但必须标注来源，有条件的话找第二个来源验证
- **社区/视频**：必须交叉验证，不能单独作为事实依据

## 二、如何检索信息

### 2.1 按内容类型选择来源

| 你要找什么 | 优先用什么来源 | 搜索方法 |
|-----------|--------------|---------|
| 游戏基本信息 | 官方网站、Steam商店 | 直接访问官网 |
| 角色基本信息 | Wiki、官方资料 | Google: "game name wiki characters" |
| 技能名称和效果 | Wiki、英文攻略站、小语种站 | Google: "game name character skills" |
| 配装/培养方案 | 英文攻略站、中文站、小语种站 | Google: "game name best build" |
| 队伍搭配/combo | 英文攻略站、YouTube、小语种站 | Google: "game name best team" + YouTube搜索 |
| Tier排名 | 英文攻略站、YouTube | Google: "game name tier list" + YouTube |
| 游戏系统机制 | Wiki、英文攻略站 | Google: "game name [系统名] guide" |
| 配方/数据表 | Wiki、小语种站（意大利/俄文） | Google: "game name recipes list" |
| 角色背景故事 | Wiki、小语种站（俄文/中文） | Google: "game name character lore" |
| 评测/评分 | Metacritic、Steam、媒体评测 | Google: "game name review metacritic" |
| 更新计划/路线图 | 官方公告、媒体新闻 | Google: "game name roadmap update" |
| Boss打法 | YouTube、英文攻略站 | YouTube搜索 + Google: "game name boss guide" |
| 操作技巧 | YouTube、Reddit | YouTube搜索 + Reddit搜索 |

### 2.2 Google搜索技巧

**基础搜索：**
- 精确匹配：用引号，如 `"dragonsword awakening best team"`
- 排除词：用减号，如 `dragonsword awakening build -mod -cheat`
- 限定站点：用site:，如 `site:progameguides.com dragonsword awakening`

**按语言搜索：**
- 英文：直接搜英文关键词
- 中文：搜中文关键词，如 `龙之剑觉醒 配装`
- 日文：搜日文关键词，如 `ドラゴンソード アウェイクニング 攻略`
- 韩文：搜韩文关键词，如 `드래곤소드 어웨이크닝 공략`
- 俄文：搜俄文关键词，如 `драгон сворд авейкнинг гайд`

**按时间筛选：**
- Google搜索结果页 → 工具 → 时间 → 选择"近一个月"或"近三个月"
- 游戏更新频繁，新内容更准确

### 2.3 YouTube检索技巧

1. 搜索 `游戏名 + 关键词`，如 `dragonsword awakening tier list`
2. 筛选 → 上传时间 → 本月/本年
3. 按播放量排序，找高播放量视频
4. 用 **YouTube TranscriptGenerator** 插件提取字幕
   - 安装地址：https://chromewebstore.google.com/detail/olhmdeioemochcmndjfcgfnpmhkckgif
   - 视频页面点击"显示字幕" → 导出文本
5. 从字幕中提取关键信息

### 2.4 社区检索技巧

**Reddit：**
1. 搜索 `游戏名 reddit`，找到官方子版块
2. 子版块内用搜索功能找相关帖
3. 按"Top"排序，看高赞讨论
4. 看开发者（Dev）的回复，标记为官方信息

**Steam社区：**
1. 游戏商店页 → 社区中心
2. "讨论"标签：玩家问答
3. "指南"标签：玩家写的攻略
4. 按"最有帮助"排序

## 三、如何交叉核验

### 3.1 核验流程

对每条重要信息，按以下步骤核验：

```
找到信息 → 找第二个独立来源 → 对比是否一致 → 一致则采用 / 不一致则标注争议
```

### 3.2 什么是"独立来源"
- 不是同一个网站的不同页面
- 不是互相抄袭的两个站（很多小站会抄大站的内容）
- 最好是不同类型的来源（如攻略站 + YouTube，或英文站 + 中文站）

### 3.3 核验等级处理

| 情况 | 处理方式 | 页面中如何表述 |
|------|---------|--------------|
| ≥2个独立来源一致 | 直接采用 | 正常陈述 |
| 来源之间有差异 | 列出不同说法 | "不同来源有不同说法：A来源认为X，B来源认为Y" |
| 只有1个来源 | 谨慎使用，标注来源 | "据[来源名]介绍，..." |
| 没有来源 | 不使用 | 删除，不能编造 |

### 3.4 必须核验的信息（高风险）
- 角色技能名称、效果、数值
- 配装方案（套装、属性、Karma选择）
- 队伍搭配和combo循环
- Tier排名
- 游戏机制的具体规则
- 数字类数据（伤害、概率、持续时间等）

### 3.5 不需要严格核验的信息（低风险）
- 游戏基本介绍（官网已有）
- 操作步骤和个人经验
- 主观评价（标注"作者认为"即可）
- 常识性内容

### 3.6 发现矛盾怎么办
1. 不要选边站，把两种说法都列出来
2. 标注哪个来源更权威（官方 > 攻略站 > 社区）
3. 建议用户"以游戏内实际为准"
4. 如果后续有官方确认，再更新

## 四、如何判断来源质量

### 4.1 高质量来源特征
- ✅ 有具体数据、表格、截图
- ✅ 有明确的发布日期，且较新
- ✅ 内容有深度，不是泛泛而谈
- ✅ 作者有相关经验（如玩了多少小时）
- ✅ 评论区有玩家讨论和验证
- ✅ 网站设计专业，不是垃圾站

### 4.2 低质量来源特征（警惕）
- ❌ 内容明显是AI生成的，有事实错误
- ❌ 只有标题党，没有实质内容
- ❌ 大量广告，内容很少
- ❌ 发布日期很久远，游戏已大更
- ❌ 抄袭其他网站的内容
- ❌ 网站域名奇怪，设计粗糙

### 4.3 如何快速判断
1. 看发布日期：超过3个月的要注意是否过时
2. 看内容长度：太短的（<300字）通常没深度
3. 看是否有数据：有表格、数值的比纯文字的可信
4. 看评论：如果评论区有人指出错误，要注意
5. 交叉对比：和另一个来源对比，看是否一致

## 五、如何更新信息

### 5.1 哪些内容需要定期更新
- **Roadmap/更新计划**：每月复查，官方可能有新公告
- **Tier排名**：游戏大更新后重新验证
- **配装/队伍**：版本更新后可能变化
- **角色攻略**：新角色发布后补充
- **评测数据**：好评率可能随时间变化

### 5.2 更新频率建议

| 内容类型 | 更新频率 | 触发条件 |
|---------|---------|---------|
| Roadmap | 每月 | 官方发布新公告时立即更新 |
| Tier排名 | 每季度 | 游戏大版本更新后 |
| 配装/队伍 | 每季度 | 平衡性调整后 |
| 角色攻略 | 按需 | 新角色发布时 |
| 基础信息 | 每年 | 一般变化不大 |
| 评测 | 每半年 | 好评率可能变化 |

### 5.3 更新操作步骤
1. 检查官方渠道（官网、Discord、Steam新闻）是否有新公告
2. Google搜索最新攻略，对比现有内容
3. YouTube搜索最新视频，看是否有新发现
4. 更新素材文件，标注更新日期
5. 更新对应的网站页面

## 七、如何发现新来源

### 7.1 方法
1. **Google搜索结果**：前3页都看，不要只看第一页
2. **相关链接**：攻略站通常会互相引用，从友链发现新站
3. **YouTube描述**：视频描述里常有攻略站链接
4. **Reddit置顶帖**：子版块置顶帖通常有资源汇总
5. **Discord频道**：官方Discord的#resources频道
6. **反向链接**：用SEO工具看哪些站链接了你的竞对站

### 7.2 新来源验证
发现新来源后，先判断质量：
1. 看网站设计和内容质量
2. 找一篇已知答案的文章，看是否正确
3. 和已验证的来源对比
4. 质量合格的加入来源库

## 八、常见坑

1. **只看英文站**：小语种站常有独家深度内容，特别是俄文、韩文、日文
2. **直接复制粘贴**：有版权风险，要用自己的话重新组织
3. **不标注来源**：后续无法验证和更新，必须每个重要信息都能追溯
4. **把社区推测当事实**：Reddit上的"我觉得"不等于官方确认
5. **忽略发布日期**：旧攻略可能过时，特别是游戏大更后
6. **AI生成内容不验证**：很多攻略站的内容本身就是AI生成的，可能有错误
7. **只看一个来源**：必须交叉核验，特别是配装、数值类内容
