# 关卡3 - 素材搜集操作指南

> 文档定位：**操作手册**。照着本文档的步骤操作，可以为每个页面搜集到充足、真实、可核验的素材。
> 前置条件：已完成关卡2，有关键词清单和页面矩阵。
> 操作目标：为每个页面搜集2-5个信息源，整理成结构化.md文件，可直接用于AI生成内容。
> 预计耗时：每个页面30-60分钟，20+页面共10-20小时

---

## 一、操作总览

### 1.1 标准操作链路（单页5步，逐页循环）
```
确定页面关键词 → 五维来源检索 → 交叉核验 → 结构化整理 → 质量检查
```

### 1.2 五维来源矩阵

> 不要只看英文站！小语种站往往有英文站没有的独家深度内容。

| 维度 | 说明 | 优先级 | 怎么找 |
|------|------|--------|--------|
| 英文权威攻略站 | Pro Game Guides、games.gg等 | ⭐⭐⭐⭐⭐ 主力 | Google搜索关键词 |
| 中文攻略站 | 游侠网、52PK、游民星空等 | ⭐⭐⭐⭐ 补充验证 | 用中文关键词搜索 |
| 小语种攻略站 | 俄文、泰文、意大利文等 | ⭐⭐⭐⭐ 独家信息 | Google搜索关键词+语言限定 |
| Wiki站点 | thegameswiki、Fandom等 | ⭐⭐⭐⭐ 基础信息 | Google搜索 "game name wiki" |
| 社区/视频 | YouTube、Reddit、Steam社区 | ⭐⭐⭐ 玩家经验 | YouTube搜索、Reddit搜索 |

### 1.3 每一步的输入输出

| 步骤 | 输入 | 工具 | 输出 | 判断标准 |
|------|------|------|------|---------|
| 1. 确定关键词 | 页面矩阵 | 无 | 1个英文关键词+中文含义 | 明确页面主题 |
| 2. 五维检索 | 关键词 | Google+YouTube | 5-10个候选来源链接 | 至少覆盖3个维度 |
| 3. 交叉核验 | 候选来源 | 人工对比 | 确认的事实+争议点 | 重要信息≥2个来源一致 |
| 4. 结构化整理 | 核验后的素材 | 文本编辑 | 1个.md文件 | 符合统一格式模板 |
| 5. 质量检查 | .md文件 | 人工 | 通过/需补充 | 满足质量标准 |

## 二、第一步：确定页面关键词

### 2.1 操作方法
1. 打开关卡2输出的keywords.json
2. 按优先级排序（high → medium → low）
3. 从优先级最高的页面开始，逐页搜集
4. 每个页面对应1个英文关键词（slug）

### 2.2 搜索关键词准备
为每个页面准备3-5个搜索用的关键词变体：
- 主词：如 `dragonsword awakening tier list`
- 同义词：如 `dragonsword awakening character ranking`
- 中文词：如 `龙之剑觉醒 强度榜`
- 问题词：如 `dragonsword awakening best characters`

### 2.3 搜索意图匹配游戏阶段（来自大可乐实战教训）

> **核心洞察**：做内容站不是做你认为用户需要的内容，**是做用户真正在搜的内容**。搜索意图必须匹配游戏阶段。

**反面案例（GRAINROT，8月7号上线的新游戏）：**
- 第三天建站，做了10页"攻略站"内容：Weapons Guide、Co-op Guide、Outpost Guide
- 结果发现玩家根本不搜这些，他们在搜："黑屏进不去游戏怎么修"、"四种 Vessel 选哪个"、"和 L4D2 比怎么样"
- 从 Reddit 和社区讨论里提取真实用户问题，10页全部重写成对真实搜索的回答

**游戏阶段与内容方向匹配表：**

| 游戏阶段 | 玩家真实需求 | 内容方向 | 不要做什么 |
|---------|------------|---------|-----------|
| 上线头两周 | 故障修复、购买决策 | 黑屏修复、值不值得买、对比同类游戏、新手开局 | 深度攻略、Build优化、高难副本 |
| 上线1-2月 | 基础玩法、角色选择 | 职业选择、武器推荐、装备搭配 | 速通攻略、极限Build |
| 上线2月+ | 深度攻略、Build优化 | 高难副本、Build理论、速通攻略 | 基础入门内容（已有大量） |

**怎么发现真实搜索意图：**
1. 上线后没有流量，不急着加内容
2. 让 AI 去翻 Reddit 和 Steam 社区的新游戏讨论帖，看玩家真实在问什么
3. 用 GSC 的查询列表验证：玩家实际搜了什么词
4. 想通这一点，再决定做什么内容

## 三、第二步：五维来源检索

### 3.1 维度1：英文权威攻略站（主力来源）

**操作步骤：**
1. 打开 Google（无痕模式）
2. 搜索 `游戏名 + 关键词`，如 `dragonsword awakening tier list`
3. 前3页结果都要看，不要只看第一页
4. 重点关注以下域名（权威攻略站）：
   - progameguides.com
   - games.gg
   - allthings.how
   - nerdschalk.com
   - destructoid.com
   - thegamer.com
   - gamertweak.com
   - game8.co
5. 点击进入，浏览内容，记录：
   - 页面URL
   - 核心内容要点
   - 数据/表格（如Tier排名、配装方案）
   - 发布日期（越新越好）

**判断来源质量：**
- ✅ 有具体数据、表格、步骤 = 高质量
- ⚠️ 只有泛泛而谈、没有具体内容 = 低质量
- ❌ 内容明显是AI生成的、有错误 = 不可用

### 3.2 维度2：中文攻略站（补充验证）

**操作步骤：**
1. 用中文关键词搜索，如 `龙之剑觉醒 强度榜`
2. 重点关注：
   - 游侠网（ali213.net）
   - 52PK（52pk.com）
   - 游民星空（gamersky.com）
   - 3DM（3dmgame.com）
   - GameKee（gamekee.com）
   - 九游（9game.cn）
3. 中文站的优势：
   - 有时候比英文站更详细（特别是配装、队伍搭配）
   - 有玩家实测经验
   - 角色翻译和背景故事可能更完整

**注意**：中文站的翻译可能与官方有差异，需要和英文站交叉验证。

### 3.3 维度3：小语种攻略站（独家信息来源，重点！）

> 这是最容易被忽略但价值最高的维度。很多小语种站有英文站没有的深度内容。

**操作步骤：**
1. Google搜索时加语言限定，或用Google翻译辅助浏览
2. 重点关注的语言和站点：
   - **俄文**：vgtimes.ru、mmo13.ru、stopgame.ru、infernal-duck.com
   - **日文**：4gamer.net、famitsu.com、gamewith.jp
   - **韩文**：inven.co.kr、ruliweb.com（开发商是韩国公司，韩文资源可能最丰富）
   - **泰文**：online-station.net
   - **意大利文**：techgaming.it、gamerbrain.net
   - **西班牙文**：playguias.com、vandal.elespanol.com
   - **法文**：jeuxonline.info、gamekult.com
3. 用Chrome的"翻译为中文"功能浏览
4. 记录独家信息（英文站没有的内容）

**小语种站的典型独家内容：**
- 更详细的配队思路和combo循环
- 角色技能的具体数值
- 玩家实测的装备搭配
- 角色背景故事和性格描述

### 3.4 维度4：Wiki站点（基础信息）

**操作步骤：**
1. Google搜索 `游戏名 wiki`，如 `dragonsword awakening wiki`
2. 常见Wiki：
   - thegameswiki.com
   - fandom.com（如果有）
   - 游戏官方Wiki
   - 玩家自建Wiki
3. Wiki适合搜集：
   - 角色基本信息（名字、阵营、特性）
   - 游戏系统基础说明
   - 世界观和背景故事
   - 术语表

**注意**：Wiki内容可能更新不及时，需要和攻略站交叉验证。

### 3.5 维度5：社区/视频（玩家经验、最新发现）

**YouTube操作步骤：**
1. 打开 YouTube，搜索 `游戏名 + 关键词`
2. 筛选：上传时间选"本月"或"近3个月"
3. 找播放量高的攻略视频
4. 用 **YouTube TranscriptGenerator** 插件提取字幕
   - 安装插件后，视频页面会显示"显示字幕"按钮
   - 导出字幕为文本文件
5. 从字幕中提取：
   - 具体操作技巧
   - 玩家实测的配装/队伍
   - 最新发现的机制

**YouTube字幕的独特价值（来自大可乐实战）：**
> YouTube字幕是宝藏，能挖到不少官方 wiki 不写的实战经验。

**真实案例（Necesse）：**
- Blood Bolt 的弹幕是自动追踪的，打 boss 不用瞄准专注躲就行
- Sage and Grit 是召唤师最难打的 boss，近战召唤物追不上，得换远程召唤
- Night Swarm 有七段攻击循环，得带 AOE 武器

**字幕坑（必须注意）：**
- 视频自动字幕错漏很多："Cursed Crone"会被写成"Cursed Crown"，"Sage and Grit"写成"Sluggy and Grit"
- **必须和官方 wiki 交叉核对再上站**，不能直接用字幕内容

**Reddit/Steam社区操作步骤：**
1. 搜索 `游戏名 reddit`，找到官方子版块
2. 用搜索功能找相关讨论帖
3. 重点看：
   - 高赞讨论（玩家共识）
   - 开发者回复（官方信息）
   - 攻略汇总帖
4. Steam社区的"指南"（Guides）标签也有很多玩家攻略

**注意**：社区内容质量参差不齐，需要交叉验证，不能直接采用单一帖子的说法。

### 3.6 本步输出
每个页面5-10个候选来源，记录：
- URL
- 来源类型（英文站/中文站/小语种/Wiki/视频/社区）
- 核心内容摘要
- 可信度初判（高/中/低）

### 3.7 采集深度要求：必须提取完整正文，禁止只做摘要

> **核心教训**（来自航海队员实战复盘）：问题不在于 AI 不会写，而在于我们给它的素材太薄。如果上游输入只有标题和摘要，下游再怎么要求"写得丰富一点"，也很容易变成扩写废话。

**反面案例：**
- 让 AI 按自己的方式总结并记录同行页面 → 原本完整的页面被压缩成摘要
- AI 生成内页时，为了不凭空编造，只能围绕摘要来写 → 页面"看起来结构完整（H1+H2+正文），实际都是一问一答，每个问题两三句话，真正传递的信息很少"
- 页面视觉上很大气，但信息密度极低

**正确做法：**
1. 对需要深入分析的同行页面，**逐个打开并提取完整正文**保存到本地（`03-content-materials/raw/` 目录）
2. 完整正文包括：文字、表格数据、步骤说明、问答、事实边界
3. AI 有了完整输入后，才能真正看清楚同行页面包含哪些信息、功能、表格、问答和事实边界
4. 内页内容丰富度目标：**600-800 英文单词**（不设硬指标，作为信息密度参考；不是所有页面都适合加表格/数据/步骤，不为凑字数强行添加）

**提取正文 ≠ 照抄发布：**
- 提取正文只是为了**内部研究**，不是让 AI 换个说法照抄
- 公开内容仍需经过：需求提炼 → 结构重组 → 事实核对 → 独立撰写 → 相似度检查
- 最终发布的页面必须是独立撰写的，与来源不构成抄袭

## 四、第三步：交叉核验

### 4.1 为什么要交叉核验
- 不同来源可能有不同说法
- 游戏较新时，很多信息来自玩家推测，可能不准确
- AI生成的攻略可能有错误
- 必须确保输出的内容是真实的

### 4.2 核验方法

**对每条重要信息，问三个问题：**
1. 有几个来源这么说？
2. 来源之间是否一致？
3. 有没有来源持不同意见？

**核验等级：**

| 等级 | 条件 | 处理方式 |
|------|------|---------|
| ✅ 确认 | ≥2个独立来源一致 | 直接采用 |
| ⚠️ 有争议 | 来源之间说法不同 | 标注"社区有争议"，列出不同说法 |
| ❌ 单一来源 | 只有1个来源这么说 | 标注"来自单一来源，待验证"，谨慎使用 |
| ❌ 无来源 | 没有找到来源 | 不使用，不能编造 |

### 4.3 必须核验的信息类型
- 角色技能名称和效果
- 配装方案（套装、属性优先级）
- 队伍搭配和combo循环
- Tier排名
- 数值数据（伤害、倍率等）
- 游戏机制说明

### 4.4 不需要严格核验的信息
- 游戏基本介绍（官网已有）
- 操作步骤类内容（个人经验）
- 主观评价（可以标注"作者认为"）

### 4.5 常见坑
- **坑1**：只看一个来源就直接用。特别是竞对站的内容，可能本身就有错误。
- **坑2**：把社区的推测当事实。Reddit上的"我觉得"不等于官方确认。
- **坑3**：忽略发布日期。游戏更新后旧攻略可能过时。
- **坑4**：AI生成内容看起来很专业但实际是编的。要找原始来源验证。

### 5.3 不同页面类型的素材要点

#### 攻略页（beginner-guide、boss、endgame等）
- 必须有：步骤说明、技巧、常见错误
- 重点：可操作性，用户看完能照着做
- 数据：进度路线、资源优先级

#### 图鉴页（characters、tier-list）
- 必须有：完整列表、表格、分类
- 重点：全面性，覆盖所有角色/内容
- 数据：角色基本信息表、Tier排名表

#### 角色页（theresia、lute等）
- 必须有：基本信息、技能详解、配装、队伍搭配、优势劣势
- 重点：深度，单个角色的完整攻略
- 额外：背景故事（Lore），从Wiki和小语种站补充

#### 系统页（combat、gear、karma、recipes等）
- 必须有：系统机制说明、数据表、推荐/选择指南
- 重点：机制讲清楚，用户能理解原理
- 数据：状态异常列表、套装效果、配方列表

#### 评测页（review）
- 必须有：评分汇总、优点、缺点、适合谁玩
- 重点：客观，正反两面都要有
- 数据：Metacritic、Steam好评率

#### 资讯页（roadmap）
- 必须有：已确认内容、考虑中、无计划、时间线
- 重点：区分官方确认和传闻
- 标注：信息来源和日期

### 5.4 整理技巧
- **不要直接复制粘贴**：用自己的话重新组织，避免版权问题
- **保留数据表格**：数值类内容必须准确，不能改
- **标注来源**：每个重要数据都要能追溯到来源
- **结构化优先**：用标题、列表、表格，不要大段文字
- **可直接用于AI生成**：整理后的内容应该可以直接喂给AI生成页面

## 六、第五步：质量检查

### 6.1 检查清单

每个素材文件完成后，逐项检查：

| 检查项 | 标准 | 通过 |
|--------|------|------|
| 信息来源数量 | ≥2个，大部分页面3-5个 | ☐ |
| 来源维度 | 至少覆盖3个维度（英文/中文/小语种/Wiki/视频） | ☐ |
| 交叉核验 | 重要信息≥2个来源一致，争议点已标注 | ☐ |
| 内容完整性 | 包含核心内容、数据、技巧、常见错误 | ☐ |
| 结构化 | 符合统一格式模板，有标题层级 | ☐ |
| 无编造 | 所有事实性内容都有来源，没有AI编造 | ☐ |
| 无版权问题 | 用自己的话整理，没有大段复制 | ☐ |
| SEO元数据 | 有Title、Description、H1建议 | ☐ |

### 6.2 不通过怎么办
- 来源不足 → 回到第二步，补充检索
- 有争议未解决 → 标注清楚，不要强行下结论
- 内容不完整 → 补充缺失的部分（技巧、常见错误等）
- 有编造嫌疑 → 删除无来源的内容，重新找来源

## 七、批量操作建议

### 7.1 工作流
1. 先做优先级高的页面（high）
2. 同类页面一起做（如4个角色页连续做，效率高）
3. 每完成5个页面做一次整体检查
4. 全部完成后做汇总表

### 7.2 素材库汇总表
所有页面完成后，输出一个汇总表：
- 每个页面的文件名、关键词、来源数量、文件大小
- 按分类统计
- 信息来源统计（用了哪些站，各涉及多少页面）
- 质量说明和待确认项
