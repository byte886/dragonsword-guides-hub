# GA & GSC 使用指南：如何查看关键指标

> 本文档教你如何使用 Google Analytics (GA) 和 Google Search Console (GSC) 查看网站数据。
> GA 看"用户在网站内做了什么"，GSC 看"用户怎么从 Google 找到你"。
> 官方文档：[GA4 帮助中心](https://support.google.com/analytics) | [GSC 帮助中心](https://support.google.com/webmasters)

---

## 1. 两个工具的分工

```
用户在 Google 搜索 "dragonsword awakening tier list"
        │
        ▼
   GSC 记录：展示了多少次、排第几、点了没点
        │
        ▼
   用户点击进入网站
        │
        ▼
   GA 记录：来了多少人、看了哪些页、停留多久、从哪国来
```

| 问题 | 用哪个工具 |
|------|-----------|
| 网站今天来了多少人？ | GA |
| 用户搜什么关键词找到我的？ | GSC |
| 哪些页面最受欢迎？ | GA |
| 我的页面在 Google 排第几？ | GSC |
| 用户从哪些国家来？ | GA |
| Google 收录了我多少页面？ | GSC |
| 用户用手机还是电脑访问？ | GA |
| 哪些页面还没被 Google 收录？ | GSC |

## 2. Google Analytics (GA4) 使用

### 2.1 登录与选择资源

1. 打开 https://analytics.google.com/
2. 左上角确认选择：账号 `byte886` → 媒体资源 `ds-guides.wiki`
3. 如果看不到数据，点击左下角"管理"确认 Measurement ID 是 `G-6XQCHB1YYV`

### 2.2 实时报告（Realtime）

**路径**：左侧菜单 → 报告 → 实时

**看什么**：
- **过去30分钟的活跃用户数**：此刻有多少人正在你的网站上
- **每用户的页面浏览数**：平均每人看了几页
- **国家/地区**：当前用户来自哪些国家
- **页面标题**：用户正在看哪些页面
- **设备类别**：手机/桌面/平板

**什么时候用**：
- 刚部署完 GA，确认代码生效（访问网站后这里应该出现 1 个用户）
- 发了推广链接，看实时流量
- 怀疑网站挂了，看有没有实时用户

### 2.3 用户获取报告（Traffic Acquisition）

**路径**：左侧菜单 → 报告 → 用户获取 → 流量获取

**看什么**：
- **会话默认渠道分组**：
  - `Organic Search`：自然搜索（Google 等搜索引擎来的，最重要）
  - `Direct`：直接访问（输入网址或书签）
  - `Referral`：从其他网站点链接来的
  - `Social`：社交媒体来的
  - `Organic Social`：自然社交流量
- **用户数**：每个渠道来了多少人
- **参与度**：平均参与时长、每次会话浏览页数
- **转化率**：如果设置了关键事件

**什么时候用**：
- 看流量主要从哪来
- 判断 SEO 是否有效果（Organic Search 是否增长）
- 评估推广渠道效果

### 2.4 页面报告（Pages）

**路径**：左侧菜单 → 报告 → 互动度 → 网页和屏幕

**看什么**：
- **网页路径和屏幕类**：哪些页面被访问最多
- **浏览量**：每个页面被看了多少次
- **唯一用户数**：多少不同的人看了这个页面
- **平均参与时间**：用户在页面上停留多久
- **用户参与度**：有多少比例的用户是"活跃"的（停留超过10秒或有互动）

**什么时候用**：
- 找出最受欢迎的攻略页面
- 发现哪些页面没人看（可能需要优化或删除）
- 判断内容质量（停留时间长 = 内容有价值）

### 2.5 国家/地区报告

**路径**：左侧菜单 → 报告 → 用户 → 用户属性 → 国家/地区

**看什么**：
- 哪些国家的用户最多
- 各国用户的参与度差异
- 结合网站多语言（en/ja/ko/ru/zh）判断目标市场是否准确

### 2.6 设备报告

**路径**：左侧菜单 → 报告 → 技术 → 设备类别

**看什么**：
- 桌面 vs 移动 vs 平板的比例
- 如果移动用户多，确保移动端体验好
- 各设备的转化率差异

### 2.7 GA 数据延迟

- **实时报告**：立即更新（几秒内）
- **其他报告**：通常延迟 24-48 小时
- 新网站前几天数据可能不完整，属正常现象

## 3. Google Search Console (GSC) 使用

### 3.1 登录与选择资源

1. 打开 https://search.google.com/search-console
2. 左上角确认选择资源：`ds-guides.wiki`（域名类型）
3. 如果有多个资源，点击左上角下拉切换

### 3.2 搜索效果报告（Performance）

**路径**：左侧菜单 → 效果 → 搜索效果

**四个核心指标**：

| 指标 | 含义 | 怎么理解 |
|------|------|---------|
| **点击次数 (Clicks)** | 用户从 Google 搜索结果点击进入你网站的次数 | 真正带来的流量 |
| **展示次数 (Impressions)** | 你的网站在搜索结果中被看到的次数 | 曝光量，不代表有流量 |
| **点击率 (CTR)** | 点击次数 ÷ 展示次数 | 标题和描述是否吸引人 |
| **平均排名 (Position)** | 你的页面在搜索结果中的平均位置 | 1=第一位，10=第一页底部 |

**四个维度切换（页面上方标签）**：

1. **查询（Queries）**：用户搜了什么关键词看到你的网站
   - 最有价值的报告：发现你意想不到的关键词
   - 按展示次数排序，找到高曝光低点击的词（优化标题）
   - 按点击排序，找到真正带来流量的词

2. **网页（Pages）**：哪些页面在搜索结果中表现最好
   - 按点击排序，找到最有流量的页面
   - 按展示排序，找到有潜力但排名靠后的页面

3. **国家（Countries）**：搜索来自哪些国家
   - 对比 GA 的国家数据，判断流量质量

4. **设备（Devices）**：搜索来自桌面还是移动
   - 移动排名和桌面排名可能不同

**日期范围**：默认最近3个月，可调整。新网站需要等几天才有数据。

**实用筛选**：
- 按国家筛选：只看特定国家的数据
- 按页面筛选：只看某个页面的关键词排名
- 按查询筛选：包含特定词的关键词

### 3.3 索引覆盖率（Pages）

**路径**：左侧菜单 → 索引 → 网页

**看什么**：
- **已编入索引的网页数**：Google 收录了多少页面
- **未编入索引的网页数**：哪些页面没被收录，原因是什么

**常见状态**：
- `已编入索引`：正常，页面在 Google 数据库中
- `已抓取 - 尚未编入索引`：Google 爬了但还没收录，等一等
- `重复网页`：内容和其他页面太相似
- `未找到（404）`：页面不存在
- `已被 noindex 标记排除`：页面代码里禁止了索引

**什么时候用**：
- 网站上线几天后检查收录情况
- 发现页面没被收录时排查原因
- 提交新页面后确认是否被收录

### 3.4 提交 Sitemap

**路径**：左侧菜单 → 索引 → 站点地图

- 已提交：`https://www.ds-guides.wiki/sitemap.xml`
- 状态：成功 = Google 已读取
- 已发现的网址数：应该接近 115（网站总页面数）
- 如果更新了 sitemap，可点击重新提交

### 3.5 URL 检查（URL Inspection）

**路径**：顶部搜索框输入任意 URL

**用途**：
- 检查某个页面是否被 Google 收录
- 如果没被收录，点击"请求编入索引"加速收录
- 查看 Google 抓取页面时看到的内容
- 检查页面的 canonical、移动端可用性等

**什么时候用**：
- 发布了重要新页面，请求快速收录
- 某个页面排名突然消失，检查是否被移除索引
- 排查页面为什么没被收录

### 3.6 安全问题和手动操作

**路径**：左侧菜单 → 安全问题和手动操作

- **手动操作**：Google 是否因为违规惩罚了你的网站（正常应该为空）
- **安全问题**：网站是否被黑或有恶意软件（正常应该为空）
- 如果有内容，必须立即处理，否则排名会被降权

### 3.7 GSC 数据延迟

- 搜索效果数据通常延迟 **2-3 天**
- 新网站可能需要 **3-7 天**才开始显示数据
- 索引状态更新可能需要几天到几周
- sitemap 提交后状态从"无法抓取"变为"成功"通常需要几小时

## 5. 常见问题

### GA 实时报告显示 0 个用户
1. 确认 `js/analytics.js` 中的 Measurement ID 正确
2. 用浏览器无痕模式访问网站，排除插件拦截
3. 检查是否有广告拦截插件阻止了 GA
4. 查看页面源码确认 analytics.js 被引用

### GSC 显示"无法抓取"sitemap
- 刚提交时正常，等几小时再看
- 确认 sitemap URL 可以在浏览器中直接访问
- 确认 sitemap 中的 URL 格式正确（全 URL，带 https://）

### GSC 搜索效果没有数据
- 新网站需要等 3-7 天
- 确认域名验证状态正常（GSC → 设置 → 所有权验证）
- 确认 sitemap 已成功提交

### GA 和 GSC 数据对不上
- 两个工具统计口径不同，数据不会完全一致
- GA 记录的是实际访问，GSC 记录的是搜索结果中的展示/点击
- GA 可能被广告拦截器阻止，GSC 数据来自 Google 搜索日志
- 时间延迟不同：GA 24-48小时，GSC 2-3天
