# 关卡1 - 选词操作指南

> 文档定位：**操作手册**。照着本文档的步骤操作，可以从零完成"选一个游戏热词"的完整流程。
> 操作目标：找到一个KD低、搜索量够、竞争小、素材足的游戏，作为建站主题。
> 预计耗时：2-4小时

---

## 一、操作总览

### 1.1 标准操作链路（5步，必须按顺序）
```
批量收集候选词 → Google Trends热度验证 → SimilarWeb KD验证 → 谷歌首页竞争终判 → 域名规划
```

### 1.2 每一步的输入输出

| 步骤 | 输入 | 工具 | 输出 | 判断标准 |
|------|------|------|------|---------|
| 1. 收集候选词 | 无 | SteamDB + YouTube | 5-10个候选游戏名 | 新品/热度上升 |
| 2. Trends验证 | 候选游戏名 | Google Trends | 淘汰暴跌/持平的，保留上涨的 | 近30天持续上涨，对标GPTs合格 |
| 3. KD验证 | 保留的候选词 | SimilarWeb PRO | 淘汰KD>30的，保留KD≤30的 | KD 0-30可做，>40放弃 |
| 4. 竞争终判 | KD合格的词 | Google搜索 | 淘汰顶级站垄断的，保留有缝隙的 | 首页无Fandom/IGN垄断 |
| 5. 域名规划 | 最终选定的词 | 域名查询 | 1个首选域名+2-3个备选 | .wiki优先，避开.cc/.xyz |

### 1.3 最终入围标准（5条全部满足才做）
1. ✅ Google Trends近30天持续上涨，对标GPTs合格，无暴跌陷阱
2. ✅ SimilarWeb KD难度 0-30
3. ✅ 细分长尾关键词充足（>100个）
4. ✅ 谷歌首页无顶级大站垄断，有排名缝隙
5. ✅ 全网素材充足，可稳定搜集用于AI生成

## 二、第一步：批量收集候选词

### 2.1 目标
找到5-10个"近期新品或热度上升"的游戏作为候选。

### 2.2 来源1：SteamDB（找新品、增量热游）

**操作步骤：**
1. 打开 https://steamdb.info/
2. 查看以下榜单：
   - **新品榜**（New Releases）：最近1-2个月发布的游戏
   - **热销榜**（Top Sellers）：当前销量高的游戏
   - **在线人数上升榜**（Most Played → 按涨幅排序）：在线人数快速增长的游戏
3. 记录候选游戏的：游戏名、开发商、发布日期、当前在线人数、评价数

**筛选标准：**
- 优先：发布1-3个月内的新游戏（大站还没反应过来，竞争小）
- 优先：在线人数持续上升的游戏
- 避开：发布超过1年的老游戏（竞争已经很充分）
- 避开：在线人数暴跌的游戏

### 2.3 来源2：YouTube（找预售/上新游戏视频）

**操作步骤：**
1. 打开 YouTube，搜索 `gameplay trailer 2026` 或 `new game release 2026`
2. 筛选：上传时间选"本月"或"近3个月"
3. 找播放量快速增长的新游戏预告/实机视频
4. 记录游戏名，补充到候选列表

**判断技巧：**
- 看视频发布时间和播放量的比值，发布时间短但播放量高 = 热度上升快
- 看评论区是否有玩家在问"什么时候出"、"怎么玩" = 有搜索需求

### 2.4 本步输出
一个候选游戏列表（5-10个），格式：
```
| 游戏名 | 开发商 | 发布日期 | 来源 | 备注 |
|--------|--------|---------|------|------|
| Game A | XXX | 2026-07-23 | SteamDB新品榜 | 在线人数上升中 |
| Game B | XXX | 2026-08-01 | YouTube | 预告片播放量高 |
```

## 三、第二步：Google Trends 热度真伪验证

### 3.1 目标
验证候选游戏的**真实搜索热度**，淘汰社媒热但搜索不热的、以及暴跌陷阱词。

### 3.2 操作步骤

1. 打开 https://trends.google.com/
2. 输入候选游戏名（英文）
3. 设置参数：
   - **地区**：全球（Worldwide）
   - **时间范围**：近30天（Past 30 days）
   - **类别**：全部类别
   - **搜索类型**：网页搜索（Web Search）
4. 查看热度走势图

### 3.3 对标基准词：GPTs

Google Trends只显示0-100的**相对热度**，不显示真实搜索量。需要用一个已知搜索量的词做对标。

**对标方法：**
1. 在Trends中同时输入候选游戏名 + `GPTs`
2. 对比两条线的高度
3. GPTs的日均搜索量约3000-5000

**判断规则：**
| 热度对比 | 判断 | 操作 |
|---------|------|------|
| ≈ GPTs的1/3 | 可备选 | 保留，继续验证 |
| ≈ GPTs | 优质 | 保留，优先级高 |
| 大幅超过GPTs | 强趋势爆发 | 保留，最高优先级 |
| 远低于GPTs | 搜索量太小 | 淘汰 |

### 3.4 趋势线型判断（避坑重点）

| 线型 | 含义 | 判断 |
|------|------|------|
| 缓步上行 | 热度稳定增长 | ✅ 保留 |
| 持平 | 没有增长动力 | ❌ 淘汰 |
| 下行 | 热度在衰退 | ❌ 淘汰 |
| 山峰骤涨骤跌 | 短期热点，很快过气 | ❌ 陷阱词，淘汰 |
| 7天内快速拉升 | 新游戏爆发期 | ✅ 最优赛道 |

### 3.5 常见坑
- **坑1**：只看绝对热度值，不看趋势方向。热度高但在下跌的词不能做。
- **坑2**：地区选了某个国家而非全球。出海站要做全球流量，必须选"全球"。
- **坑3**：时间范围选了"近12个月"，看不清近期变化。选词必须看"近30天"。

### 3.6 本步输出
淘汰后的候选列表，每个词标注：
- 热度对比GPTs的结果
- 趋势线型（上涨/持平/下跌/山峰）
- 是否保留

## 四、第三步：SimilarWeb 双维度校验

### 4.1 目标
验证两个核心指标：**KD关键词难度**（能不能排上去）和**长尾关键词数量**（能不能做足够多页面）。

### 4.2 前置准备
- SimilarWeb PRO账号（本项目已准备，登录账号：wen）
- 如果没有PRO账号，免费版也能看部分数据，但KD列可能受限

### 4.3 操作步骤：查KD

1. 打开 https://www.similarweb.com/
2. 进入 **关键词生成器**（Keyword Generator）
3. 输入候选游戏的主词（如 `dragonsword awakening`）
4. 选择地区：全球（Global）
5. 查看"语句匹配"（Phrase Match）标签

### 4.4 关键操作：找到KD列（重点避坑）

**KD列不在默认可见区域！** 这是新手最容易踩的坑。

SimilarWeb关键词表格的列包括：
```
关键词 | 28天的体量 | 平均体量 | 年趋势 | 零点搜索 | KD | 意图 | CPC | 领先者
```

默认只显示前几列，KD列在后面。**两种方法找到KD：**

**方法1（推荐）：** 用表格底部的**左右箭头按钮**切换列组，点右箭头直到看到KD列。

**方法2：** 点击表格右上角的**列设置图标**（表格形状），勾选KD（默认已勾选），然后横向滚动表格。

### 4.5 KD判断标准

| KD值 | 难度 | 新手操作建议 |
|------|------|------------|
| 0-10 | 极低 | ✅ 闭眼做，几乎没有竞争 |
| 11-30 | 低 | ✅ 可做，新手友好 |
| 31-40 | 中等 | ⚠️ 谨慎，需要内容质量很高 |
| 41-60 | 较高 | ❌ 放弃，新手做不动 |
| 61-100 | 极高 | ❌ 放弃，大站垄断 |

**注意**：
- 看**长尾词的KD**，不是主词的KD。主词KD通常较高，我们做的是长尾词。
- 重点看 tier list、characters、build、guide 这类核心攻略词的KD。
- 如果核心长尾词KD≤30，就合格。

### 4.6 操作步骤：查长尾关键词数量

1. 在同一个SimilarWeb关键词生成器页面
2. 查看以下4个标签的数量：
   - **语句匹配**（Phrase Match）：包含主词的关键词总数
   - **相关关键词**（Related）：语义相关的词
   - **热门关键词**（Top）：按搜索量排序
   - **问题查询**（Questions）：用户的真实疑问
3. 另外查看 **YouTube关键词** 标签（视频搜索需求）

### 4.7 长尾数量判断标准

| 语句匹配总数 | 判断 | 操作 |
|------------|------|------|
| <50 | 太少 | ❌ 淘汰，做不出足够页面 |
| 50-200 | 一般 | ⚠️ 勉强可做，页面矩阵有限 |
| 200-1000 | 充足 | ✅ 可做，能规划20+页面 |
| >1000 | 非常充足 | ✅ 优先选，扩展性强 |

### 4.8 常见坑
- **坑1**：把"零点搜索"当成KD。零点搜索是"零点击率百分比"，不是关键词难度。KD列在更后面。
- **坑2**：只看主词的KD，不看长尾词。主词KD高很正常，我们做长尾词。
- **坑3**：只看搜索量，不看KD。搜索量再大，KD太高排不上去也没用。
- **坑4**：忽略问题查询。问题查询（Questions）是用户的真实疑问，内容最好做。

### 4.9 本步输出
每个候选词的：
- 核心长尾词KD值（至少查5个核心词：tier list、characters、build、guide、map）
- 语句匹配总数
- 问题查询数量
- 是否合格

## 五、第四步：谷歌首页人工竞争终判

> **选词铁律（来自大可乐实战踩坑）：工具数据必须用"手动搜首页"验证，首页竞争是辨别数据真假的唯一标准。**
>
> SimilarWeb/Google Trends 显示的搜索量、KD 等数据可能骗人。工具说"搜索量过万、KD Easy"不代表真的能做——必须手动打开 Google 搜索首页，看前10名实际是什么站，新站有没有位置。
>
> **核心结论：游戏名主词都是大站的，新站唯一的机会在"游戏名 + 细分长尾词"。**

### 5.1 目标
人工查看谷歌搜索结果首页，判断实际竞争强度，找出排名缝隙。

### 5.2 操作步骤

1. 打开 Google（建议用无痕模式，避免个性化结果影响）
2. 搜索候选游戏的核心长尾词，如 `game name tier list`
3. 查看首页前10个结果
4. 对每个结果判断属于哪一类竞品

### 5.3 五类竞品层级（从强到弱）

| 层级 | 典型站点 | 权重 | 能否竞争 |
|------|---------|------|---------|
| 1 | Fandom、Wiki百科大站 | 极高 | ❌ 几乎无法竞争 |
| 2 | 游戏官方Wiki | 高 | ⚠️ 权威但更新不及时，有缝隙 |
| 3 | IGN、GameSpot、PC Gamer等头部媒体 | 高 | ⚠️ 权重高但内容偏新闻评测，攻略不深 |
| 4 | Pro Game Guides、Game8、games.gg等垂直攻略站 | 中 | ✅ 你的对标竞品，可以拼内容质量 |
| 5 | Steam商店页、媒体单篇评测、Reddit帖 | 低-中 | ✅ 最容易超车 |

### 5.4 判断标准

| 首页情况 | 判断 | 操作 |
|---------|------|------|
| 前10全是Fandom/IGN等顶级站 | 垄断 | ❌ 放弃，新手挤不进去 |
| 前10有3个以上顶级站，其余是垂直站 | 竞争激烈 | ⚠️ 谨慎，需要差异化内容 |
| 前10以垂直攻略站和社区为主 | 有缝隙 | ✅ 可入局，拼内容深度 |
| 前10有很多Steam页/Reddit/单篇评测 | 缝隙大 | ✅ 优先做，容易排名 |

### 5.5 辅助工具：SiteData插件
Chrome插件SiteData可以在谷歌搜索页直接显示：
- 竞品网站月流量
- 域名年龄
- DR权重（域名权重）

**使用方法：**
1. 安装SiteData Chrome插件
2. 在Google搜索结果页，每个结果下方会自动显示流量/DR/年龄
3. DR<40的站 = 容易超车；DR>70的站 = 很难竞争

### 5.6 常见坑
- **坑1**：只看搜索结果数量，不看质量。"约有1,000,000条结果"这个数字没意义，要看前10的质量。
- **坑2**：用中文Google搜索。要做英文站，必须用英文关键词在Google英文环境搜索。
- **坑3**：登录了Google账号，结果被个性化。建议用无痕模式。
- **坑4（大可乐踩过）：工具数据骗人。** SimilarWeb/Trends 显示搜索量过万、KD Easy，手动一搜才发现是手游 APP，首页被 Google Play 垄断，内容站根本没位置。**反面案例：meccha chameleon**——工具看着像金矿，实际是手游APP。
- **坑5（大可乐踩过）：游戏主词 KD 全在40以上，不要硬刚。** 必须下钻到"游戏名 + 细分长尾词"（如 `necesse mods`），KD 才会显示 Easy、首页全是小站。
- **坑6：大站速查表。** Wikipedia、Fandom、IGN、Steam、官网在第一梯队，**见到就撤**；Reddit 和小博客在第四梯队，**那才是新站的机会**。

### 5.7 本步输出
每个候选词的：
- 首页前10结果的竞品层级分布
- 是否有排名缝隙
- 最终判定（做/不做）

## 六、第五步：域名规划

### 6.1 目标
为选定的游戏规划一个合适的域名。

### 6.2 域名选择原则

| 原则 | 说明 |
|------|------|
| 先验证后买 | 必须完成前面4步验证再买域名，禁止凭预感囤域名 |
| 后缀优选 | .wiki ＞ .com/.org/.net/.online/.site |
| 后缀避雷 | 严禁.cc、.xyz等灰产高频后缀 |
| 域名本身 | 简短、好记、和游戏相关，不需迷信特殊后缀 |

### 6.3 域名命名思路
- 游戏缩写 + guides/wiki：如 `ds-guides.wiki`、`ds-wiki.com`
- 游戏全名 + guides/wiki：如 `dragonsword-guides.com`
- 游戏名 + 功能词：如 `dragonswordawakening.guide`

### 6.4 购买平台
- **推荐**：Spaceship（https://www.spaceship.com/），支持支付宝，价格便宜
- 备选：Namecheap、Cloudflare Registrar

### 6.5 操作步骤
1. 在Spaceship搜索心仪的域名是否可用
2. 记录1个首选 + 2-3个备选
3. **新手可以暂时不买**，等网站做好要上线时再买（域名按年付费，早买浪费）

### 6.6 本步输出
- 首选域名1个
- 备选域名2-3个
- 购买平台和预估价格
