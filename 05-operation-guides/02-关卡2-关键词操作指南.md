# 关卡2 - 关键词挖掘与页面矩阵操作指南

> 文档定位：**操作手册**。照着本文档的步骤操作，可以从零完成"挖掘关键词→清洗→分类→规划页面矩阵"的完整流程。
> 前置条件：已完成关卡1，选定了一个游戏。
> 操作目标：得到20-30个有价值的关键词，规划出完整的页面矩阵，输出keywords.json。
> 预计耗时：3-5小时

---

## 一、操作总览

### 1.1 标准操作链路（4步，必须按顺序）
```
三大来源挖掘关键词 → 四步清洗 → MECE分类 → 规划页面矩阵 + 输出keywords.json
```

### 1.2 每一步的输入输出

| 步骤 | 输入 | 工具 | 输出 | 判断标准 |
|------|------|------|------|---------|
| 1. 挖掘 | 游戏主词 | Google下拉+Trends+SimilarWeb | 原始关键词200+个 | 三大来源全部覆盖 |
| 2. 清洗 | 原始关键词 | 人工+表格 | 有效关键词20-30个 | 去掉无效词、去重、合并同义词 |
| 3. 分类 | 有效关键词 | 人工 | 8-12个分类 | MECE：相互独立、完全穷尽 |
| 4. 矩阵 | 分类后的关键词 | 人工 | 页面矩阵+keywords.json | 每个词对应一个页面，结构清晰 |

---

## 二、第一步：三大来源挖掘关键词

> 三大来源**必须全部使用**，不能只用一个。每个来源覆盖不同的搜索需求。

### 2.1 来源1：Google下拉词（自动补全）

**目标**：获取用户搜索时的真实补全词，搜索意图最明确。

**操作步骤：**
1. 打开 Google（建议无痕模式）
2. 在搜索框输入游戏主词，如 `dragonsword awakening`
3. **不要按回车**，等待自动补全下拉列表出现
4. 记录所有补全建议（约10个）
5. 继续输入空格 + 字母a-z，获取更多补全（如 `dragonsword awakening a`、`dragonsword awakening b`...）
6. 也可以输入疑问词：`dragonsword awakening how`、`dragonsword awakening what`、`dragonsword awakening best`

**记录格式：**
```
| 关键词 | 来源 | 备注 |
|--------|------|------|
| dragonsword awakening characters | Google下拉 | 角色相关 |
| dragonsword awakening tier list | Google下拉 | 强度榜 |
| dragonsword awakening best team | Google下拉 | 配队 |
```

**数量预期**：约10-30个

### 2.2 来源2：Google Trends 相关查询

**目标**：获取按搜索量和增长速度排序的相关词。

**操作步骤：**
1. 打开 https://trends.google.com/
2. 输入游戏主词，地区选全球，时间选近30天
3. 向下滚动到"相关查询"（Related queries）区域
4. 有两个标签，**两个都要记录**：
   - **热门查询**（Top）：按搜索量排序，记录前50个
   - **热度上升查询**（Rising）：按增长速度排序，记录前50个
5. 点击"在Google搜索中打开"可以查看更多

**重点关注：**
- 上升查询中增长最快的词（标记为"飙升"的）= 新兴需求，竞争小
- 热门查询中搜索量大的词 = 稳定需求

**记录格式：**
```
| 关键词 | 来源标签 | 搜索量/增长 | 备注 |
|--------|---------|-----------|------|
| theresia | 上升查询 | 飙升+5000% | 角色名，热度增长快 |
| tier list | 热门查询 | 高 | 稳定需求 |
```

**数量预期**：约100个（50热门+50上升）

### 2.3 来源3：SimilarWeb 关键词生成器

**目标**：获取最全面的关键词数据，包括搜索量和KD。

**操作步骤：**
1. 打开 https://www.similarweb.com/，进入关键词生成器
2. 输入游戏主词，地区选全球
3. 查看4个标签，**每个标签都要记录**：
   - **语句匹配**（Phrase Match）：包含主词的关键词，按搜索量排序，记录前100个
   - **相关关键词**（Related）：语义相关的词，记录前50个
   - **热门关键词**（Top）：按搜索量排序
   - **问题查询**（Questions）：用户的真实疑问，全部记录（通常50-100个）
4. 切换到 **YouTube关键词** 标签，记录前50个（视频搜索需求）

**重点记录字段：**
- 关键词
- 28天搜索量
- KD（关键词难度，参考关卡1的方法找到KD列）
- 意图（信息型/交易型/导航型）

**数量预期**：约200-300个

### 2.4 三大来源对比

| 来源 | 数量 | 优势 | 劣势 |
|------|------|------|------|
| Google下拉词 | 10-30 | 搜索意图最明确 | 数量少 |
| Google Trends | 100 | 能发现新兴需求 | 没有搜索量绝对值 |
| SimilarWeb | 200-300 | 数据最全，有KD和搜索量 | 需要PRO账号 |

### 2.5 本步输出
一个原始关键词总表（200+个），包含：关键词、来源、搜索量（如有）、KD（如有）、备注。

## 三、第二步：四步清洗

> 原始关键词有很多无效词、重复词、同义词，需要清洗后才能用。

### 3.1 第一步：过滤（去掉低价值/无关词）

**操作方法**：逐行检查，遇到以下类型直接删除。

**必须删除的词类型：**

| 类型 | 示例 | 删除原因 |
|------|------|---------|
| 中文/其他语言 | 龙刃觉醒、什么游戏、tro choi gi | 做英文站，非英文词没用 |
| 作弊/盗版相关 | mod、trainer、cheat、crack、torrent、key、nude mod | 广告联盟禁止，绝对不能做 |
| 购买/平台相关 | price、steam、ps5、switch、download、deluxe edition | 流量低，用户搜完就走，留不住 |
| 社区相关 | reddit、discord、nexus、wiki | 用户直接去社区，不会留在你的站 |
| 其他游戏 | granblue relink、genshin impact、grim dawn | 不是目标游戏 |
| 开发商/主词变体 | hound13、dragon sword awakening、dragon-sword-awakening | 主词竞争大，新手做不动 |
| 时效性强 | release date、launch time | 发售日期，过时后没人搜 |
| 法律/新闻类 | injunction decision、ban、lawsuit | 新闻热点，时效性强 |
| 低价值资讯 | trailer、ost、before you buy、gameplay | 用户看完就走，没有攻略价值 |
| 成人内容 | nude、sex、hentai | 绝对禁止 |

**操作技巧：**
- 可以用Excel/表格的筛选功能，按关键词包含的字符批量筛选删除
- 比如筛选包含 "mod" 的行，批量删除
- 筛选包含中文的行，批量删除

### 3.2 第二步：去重

**操作方法**：
1. 把所有关键词转成小写（统一格式）
2. 去掉首尾空格
3. 按字母排序
4. 删除完全重复的词，只保留一次

**注意**：有些词看起来不同但实际是同一个，如 `tier list` 和 `tierlist`，这一步先不处理，留到第三步合并同义词。

### 3.3 第三步：合并同义词

**操作方法**：把意思差不多的词合并，取搜索量最大、用户最常搜的那个作为"主词"。

**常见同义词组参考：**

| 同义词组 | 合并后主词 | 说明 |
|---------|-----------|------|
| characters / character / all characters / best characters / playable characters | characters | 角色图鉴 |
| best team / team / teams / best teams / team composition | best team | 最佳队伍 |
| tier list / tierlist / tier | tier list | 强度榜 |
| build / builds / best build / theresia build / frost build | build | 构建/培养 |
| map / interactive map / world map | map | 地图 |
| coop / co op / co-op | coop | 合作模式 |
| review / metacritic / rating / score | review | 评测 |
| gameplay / walkthrough / guide / beginner guide / tips / how to play | guide | 攻略/指南 |
| recipes / cooking / cook / food | recipes | 配方/烹饪系统 |
| boss / boss fight / boss guide | boss | Boss战 |
| raid / dungeon / instance | raid | 副本/突袭 |

**合并原则**：
- 取搜索量最大的那个作为主词
- 如果搜索量相近，取用户最常搜的写法（有空格的通常比连写的多）
- 记录合并关系，便于后续追溯

### 3.4 第四步：筛选（保留最有价值的）

**操作方法**：从剩下的词中，按以下三个维度评分，保留综合得分最高的20-30个。

**评分维度：**

| 维度 | 权重 | 高分标准 | 低分标准 |
|------|------|---------|---------|
| 攻略需求强度 | 40% | 用户有明确疑问，需要详细攻略 | 用户只是想看看，看完就走 |
| 搜索量 | 30% | 月搜索量>1000 | 月搜索量<100 |
| 竞争度(KD) | 30% | KD≤10 | KD>30 |

**筛选技巧**：
- 优先保留"系统词"：karma、recipes、combat等独特系统，大站可能没覆盖
- 优先保留"角色名"：每个角色可以单独做一个页面，扩展性强
- 谨慎保留"资讯词"：review、roadmap等搜索量大但用户留不住
- 必须保留"核心攻略词"：tier list、characters、best team、build，攻略站标配

### 3.5 常见坑
- **坑1**：舍不得删词，觉得每个词都有价值。实际上大部分词都是无效的，清洗后能留下20-30个就不错了。
- **坑2**：只看搜索量，不看攻略需求。release date搜索量很大，但过时后没人搜，不能做。
- **坑3**：忽略作弊词的搜索量。mod、trainer搜索量很大但绝对不能做，广告联盟会封号。
- **坑4**：同义词不合并。characters和character分成两个词，会导致内容重复。

### 3.6 本步输出
清洗后的关键词清单（20-30个），每个词标注：搜索量、KD、中文含义、优先级。

## 四、第三步：MECE分类

### 4.1 什么是MECE
- **M**utually **E**xclusive：相互独立，每个词只属于一个分类
- **C**ollectively **E**xhaustive：完全穷尽，所有词都有分类

### 4.2 操作步骤

1. 把清洗后的关键词全部列出来
2. 按"用户搜索意图"分组，而不是按"词面意思"分组
3. 给每个组起一个分类名
4. 检查：每个词是否只在一个分类里？所有词是否都有分类？
5. 调整：如果一个词同时属于两个分类，拆分或重新定义分类边界

### 4.3 常见分类参考（游戏攻略站）

| 分类 | 包含的关键词类型 | 示例 |
|------|----------------|------|
| Guide | 新手指南、入门攻略 | beginner guide、tips、walkthrough |
| Tier List | 强度榜、排名 | tier list |
| Characters | 角色图鉴、角色攻略 | characters、theresia、lute |
| Builds | 角色构建、配装 | build、best build |
| Best Team | 配队、队伍推荐 | best team、team composition |
| Combat & Progression | 战斗、职业、装备 | combat、classes、gear |
| Boss & Raid | Boss战、副本 | boss、raid、dungeon |
| Map | 地图、探索 | map、interactive map |
| Game Systems | 游戏独特系统 | karma、recipes、endgame |
| Multiplayer | 联机、多人 | coop、multiplayer |
| Review | 评测 | review、metacritic |
| Roadmap | 更新、路线图 | roadmap、update |

### 4.4 分类数量建议
- 太少（<5个）：分类太粗，导航不清晰
- 太多（>15个）：分类太细，用户记不住
- 合适：8-12个分类

### 4.5 本步输出
- 分类列表（8-12个）
- 每个分类下的关键词
- 分类说明（这个分类解决用户什么问题）

## 五、第四步：规划页面矩阵 + 输出keywords.json

### 5.1 页面矩阵规划

**操作方法**：
1. 每个关键词对应一个页面
2. 首页单独算一个页面
3. 角色攻略类：每个角色一个独立页面
4. 系统类：每个系统一个页面
5. 画出页面结构图（树状结构）

**页面结构示例：**
```
首页 (index.html)
├── Guide
│   └── beginner-guide.html
├── Tier List
│   └── tier-list.html
├── Characters
│   ├── characters.html      (角色图鉴总页)
│   ├── theresia.html        (角色详情页)
│   ├── lute.html
│   └── ...
├── Builds
│   └── build.html
└── ...
```

**页面类型定义：**

| 页面类型 | 说明 | 内容特点 |
|---------|------|---------|
| 首页 | 网站入口 | 游戏介绍、导航、热门内容 |
| 攻略页 | 详细攻略 | 步骤、技巧、常见错误 |
| 图鉴页 | 列表展示 | 表格、卡片、筛选 |
| 角色页 | 单个角色详情 | 技能、配装、队伍、背景故事 |
| 系统页 | 游戏系统详解 | 机制说明、数据表、推荐 |
| 评测页 | 游戏评测 | 评分、优缺点、总结 |
| 资讯页 | 新闻/更新 | 时间线、已确认/传闻 |

### 5.2 输出keywords.json

**JSON结构：**
```json
{
  "game": "游戏英文名",
  "domain": "规划的域名",
  "total_keywords": 数量,
  "categories": [
    {
      "name": "分类名",
      "keywords": [
        {
          "slug": "url路径，如 beginner-guide",
          "keyword": "英文关键词",
          "chinese": "中文含义",
          "search_volume": "月搜索量，如 4.8K",
          "kd": 关键词难度数字或null,
          "priority": "high/medium/low",
          "page_type": "guide/listing/character/system/review/news"
        }
      ]
    }
  ]
}
```

**字段说明：**
- `slug`：URL路径，用小写字母+连字符，如 `beginner-guide`
- `search_volume`：来自SimilarWeb的28天搜索量估计
- `kd`：关键词难度0-100，没有数据填null
- `priority`：high=核心必做，medium=重要，low=补充
- `page_type`：页面类型，决定页面模板

### 5.3 本步输出
- 页面矩阵图（树状结构）
- keywords.json文件
- 页面数量统计（首页+内页）
